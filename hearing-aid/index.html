助听器:把丢失的分贝按频率补回来

老年性耳聋从 4-8 kHz 开始塌(耳蜗底回先衰老)——「听得见但听不清」:元音(低频)还在,辅音 s/t/k(高频)没了。助听器的回答是频率选择性的增益:麦克风 → ADC → 多通道宽动态范围压缩(WDRC,8-20 通道按测听图配增益:4 kHz 处 2 dB 输入给 30 dB 增益,90 dB 输入只给 5 dB——把 100 dB 的自然动态压进受损后 ~30 dB 的窗口)→ 接收器。增益不是越大越好:超过 ~60 dB,接收器漏音经耳道返回麦克风形成正反馈,2-5 kHz 尖啸——自适应反馈对消器估计漏音路径、反相抵消。双麦克风指向性在噪声里抬高信噪比,总延迟必须 <10 ms,否则口齿自听错乱。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
