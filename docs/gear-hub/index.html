内变速花鼓

公路车把二十几片飞轮挂在外面淋雨,城市车却把整套行星轮系藏进后花鼓壳:中央太阳轮直接做在轴心上,轴心被钩爪端盖固定,所以太阳轮永远不转;4 颗行星轮销在行星架上,外圈 60 齿的内齿圈与壳内鼓环相连。Willis 式 (ωs−ωc)/(ωr−ωc)=−Zr/Zs 一旦把 ωs 钉在 0,内齿圈与行星架的速度比就被锁成 80:60——花鼓的全部玄机,只是用销键棘爪选择「链轮驱动谁、谁把扭矩交给壳体」:1 速内齿圈进、行星架出,i₁=Zr/(Zr+Zs)=60/80=0.750,降速 25%、扭矩 ×1.33,起步爬坡用;2 速离合直连,i=1,轮系卸载空转,效率最高;3 速行星架进、内齿圈出,i₃=(Zr+Zs)/Zr=80/60=1.333,提速 33%、扭矩 ×0.75,顺风巡航用。三挡总范围 1.78×;踏频 60 rpm × 牙盘 44T ÷ 飞轮 18T → 链轮 147 rpm,三挡对应 13.9 / 18.5 / 24.7 km/h(700×28c 轮周 2.10 m)。换挡时把手扳机经钢缆推拉轴心内的滑套、顶出销键咬合不同棘齿圈——单向棘爪让滑行自动脱开、可停车换挡、倒脚不带动;1/3 速时反作用扭矩走轴心传给车架,钩爪要加防转垫片。整套轮系油浴密封、雨水泥沙进不去,数年免保养,链条始终走直线;代价是总范围窄、效率略逊于外露直传,Rohloff 用串联轮系把范围做到 526%,共享单车几乎清一色内变速。经典失效是输出棘爪磨损:链轮照转、花鼓不跟,当场断力——切回 2 速直传动力立刻恢复,这正是现场诊断棘爪磨损的老办法。拖「踏频/飞轮齿数」看三挡车速换算,拖「太阳轮齿数」改速比;按「挡位 1/2/3」切换销键与高亮元件,按「棘爪打滑」看断力失效。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
