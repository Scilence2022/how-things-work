扩散模型与逐步去噪:加噪一千步,学成一条反向链

前向过程把一张图逐步泡进高斯噪声:x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε,T=1000 步后 ᾱ→0、纯粹是雪花;训练一个网络 ε_θ(x_t,t) 在每个噪声水平上预测「混进来的噪声是哪一份」,损失就是预测噪声的 MSE;采样从纯噪声出发,每步按预测噪声扣掉一点、再按方差表 σ_t 加回一点随机性,反向链走 1000 步(或蒸馏到 20 步)得到一张全新图;Stable Diffusion / Midjourney 的「思考」就是这条链;同一框架换数据域,就得到视频生成、分子构象、蛋白质设计 · 3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
