对数计算尺

口袋里的计算器没有齿轮也没有电子,只靠一个恒等式干活:log(ab)=log a+log b——对数把乘法压成段长加法。1620 年冈特把对数刻成直尺,1622 年奥特雷德加上滑动,1851 年曼海姆定型现代布局。标准 250 mm 尺上,1→2 段长 75.3 mm(log₁₀2≈0.301),最小刻度约 1 mm,保 3 位有效数字、读数误差 ±0.3%(示意)。C 尺(滑动)的 1 对准 D 尺上的 a,游标移到 C 的 b,D 尺下就是积——积超 10 换 C 的右指标对齐,×10 记在脑子里;A 尺两轮回到平方、K 尺三轮回到立方,游标一条红线三层同读;CI 红尺倒着刻,读出倒数,除法变一次对齐;S/T/L 专用尺把 sin、tan、log₁₀ 也搬上尺面。失效同样清楚:线性刻度尺用同一套动作只会把段长相加,2×3 读出 4(=a+b−1);游标玻璃有高度,斜视 θ 视线在尺面偏移 tanθ×游标高,30° 就能把第二位有效数字读歪(游标垫高示意);整条尺再大也只有 3 位。1960 年代工程师胸口人手一支,波音 747 与土星五号的图纸上全是发丝线压出的读数;1972 年 HP-35 上市,五年内计算尺退进博物馆。拖「被乘数/乘数」出题,拖「视线角」制造视差,拖「尺长」换 125~500 mm 精度;按「乘法对齐」看 C 尺滑到指标、游标走位读积,按「除法·倒数」「平方立方」看 A/K/CI,按「视差失效」「线性尺对照」看两种经典读错。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
