滚筒烘干机

烘干机的本质是一门「搬运课」:把水从衣物里搬进空气、再搬出家门,路线有两条,账本截然不同。通风式是粗放派:电热管 3–5 kW 把空气烧到六七十度,热风穿过滚筒卷走水分,湿空气直接排到户外——能量收进来又全扔出去,一度电只干一度电的活;热泵式是精算派:闭式循环里,蒸发器从排出的湿空气里吸热,把水汽冷凝成水收进水箱,冷凝器再把这份热外加上压缩机做功一并还给进风——能效比 3 左右意味着一度电搬走三度电的热,耗电只有通风式的三分之一到一半,而且 50 °C 低温烘干更护衣物纤维。滚筒里的机械设计同样有讲究:提升筋把衣物抬到顶部再跌落,让每片布料轮流暴露给热风;湿度传感器靠两枚电极测布料电导,干了自动停机;反向旋转能打散缠绕成团的床单;而绒毛过滤器是安全底线——细小纤维堵住风道、热量散不出去,是烘干机火灾的头号原因。冷凝水直接排进下水,所以热泵机连排气孔都不需要,塞进任何衣柜都能开张。拖「装载湿度」看含水率如何决定工时与耗电,拖「环境温度」看进风温度怎么改写热泵账本;按「通风式路线」看电表随湿气直排飞转,按「热泵式路线」看热量在回路里循环,按「能量对比」看两只电表的转速差,按「湿度控制」看传感器如何提前停机省电。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
