鱼的渗透调节

同一条鱼,放进淡水是一张漏水漏盐的网,放进海水是一块失水进盐的海绵——渗透压永远把水从稀处拉向浓处,淡水鱼与海水鱼对付的是相反的物理题。硬骨鱼体液约 300 mOsm:淡水只有 5-50,水拼命往里渗、盐拼命往外漏——淡水鱼干脆不喝水,肾造出大量稀尿(每天排出约体重 1/3 的水),鳃上氯细胞主动把 Na⁺/Cl⁻ 泵进来补漏;海水约 1000 mOsm,水往外渗、盐往里进——海水鱼大口吞海水(每天约体重的 7-35%),肠子把水与一价盐吸收入血,多余的 NaCl 由鳃氯细胞里的 NKCC 共转运体借 Na⁺/K⁺-ATP 酶打出的电位梯度主动泵出去,二价的镁钙走肾与肠少量排出;鲨鱼走第三条路:保留尿素与 TMAO 把体液提到与海水等渗,不必喝水,鳃只对付 NaCl。洄游的鲑鱼要在两套系统间换挡:入海前鳃氯细胞从「吸盐型」改建为「排盐型」,催乳素与皮质醇在此交接;把淡水鱼苗直接扔进海水会「烧鳃」,正是这套改建需要几天。成体鱼的皮肤几乎不透水,鳃才是渗透战场的主前线——面积只有体表的几分之一,却承担九成以上的离子交换。拖「盐度」看水流方向当场翻转,拖「泵活性」看鳃的排盐速率;按「氯细胞特写」看酶泵如何借电位排盐,按「鲑鱼换挡」看两套系统的切换,按「鲨鱼方案」看尿素策略。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
