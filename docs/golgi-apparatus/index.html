高尔基体

内质网送来的蛋白质只是毛坯,高尔基体才是精加工车间:四五层扁平囊(池)平行摞成一座平台,凸面朝内质网叫 cis 面,凹面朝细胞膜叫 trans 面。货物(新合成的蛋白)由 COPII 小泡送到 cis 面入厂,然后像流水线一样逐层穿越:每一层囊膜上住着不同的糖基转移酶,给蛋白的糖链加一个、剪一个、改一个——高甘露糖型被修剪成杂合型再成熟为复杂型,半乳糖、唾液酸按顺序补上;加工完的蛋白在 trans 面被打包分拣:溶酶体酶被标上甘露糖-6-磷酸「地址签」装进网格蛋白小泡寄往溶酶体,默认路线送细胞膜,调节型分泌蛋白则存进分泌颗粒待命。整个细胞器还是动态的:囊泡在 cis 端不断并入、trans 端不断出芽,膜像传送带一样从 cis 流向 trans——它到底是「 stationary 的池子」还是「成熟的传送带」,学界吵了四十年,如今证据偏向后者:每层池自身在成熟,酶被逆行的囊泡一轮轮往回送,才保住各自的分工。高尔基体还是细胞的质检站:折叠错误的蛋白在这里被留住退回,糖链修饰错误的蛋白走不出分泌通路。拖「运输速度」看流水线节奏,拖「酶活性」看糖链加工精度;按「货运全流程」走一遍从入厂到发货,按「糖链加工」看糖链逐站修饰,按「溶酶体分选」看地址签如何决定去向,按「囊泡出芽」看膜如何弯成球。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
