陀螺罗经:惯性找真北

磁罗经在钢铁船上是废物:船体磁场能把指针拖偏几十度。1908 年安许茨与斯佩里给出解法——不靠磁,靠惯性:高速陀螺的轴在惯性系里指向不变,而地球在脚下 15°/小时地转,于是站在船上会看到陀螺轴相对地球缓慢漂移,纬度 φ 处的水平漂移速率恰为 15°·sinφ(度/小时)。诀窍是给陀螺挂上摆性配重:轴一旦偏离东-西水平位,地球自转会让轴端翘起或下沉,配重重力随即产生进动力矩,把轴往子午面推——「地球自转当引擎,重力当舵」,轴便围着真北打圈收敛,加上阻尼后几分钟内稳稳指向真北。它指的是真北而非磁北,天然免掉磁差修正,不受任何电磁干扰,潜艇、军舰、远洋巨轮至今仍以它为姿态基准;缺点是要通电启动、纬度高于约 75° 后效果衰减。相位平面上一目了然:无阻尼时轴端绕平衡点画椭圆,加阻尼变成螺旋汇入真北。演示里地球在脚下自转、陀螺仪万向环上轴端轨迹被灯光描出。拖「纬度」看漂移速率按 sinφ 变化,拖「初始偏角」换起点;按「无阻尼振荡」看椭圆,按「阻尼收敛」看螺旋入北,按「铁船对照」看磁罗经在船舱里失灵。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
