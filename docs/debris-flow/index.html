泥石流

暴雨把一条干沟变成一辆泥浆坦克,只需要四个条件凑齐:陡峭的沟床(坡度常在 10-30°)、大量松散固体物(崩塌、滑坡、老堆积体)、短时间内的高强度降雨、以及把它们搅在一起的水。泥石流的密度能到 1.8-2.3 t/m³——接近混凝土,它的力学完全是另一套账本:粗颗粒互相碰撞形成「分散应力」,把巨石「浮」在泥浆里(巨石在浪头上像软木塞一样随波逐流);细颗粒(黏土、粉砂)让浆体屈服强度暴涨,停下来的泥石流像面团一样整体搁在沟里,而不是摊成一片水。运动呈「阵性」:一场泥石流常由十几个到上百个阵波组成,龙头高 2-5 米、大石块在浪脊上翻滚,流速 5-15 m/s,冲击力是同速洪水的十几倍——1 米见方的石块以 8 m/s 撞上拦挡坝,冲击力上百吨。治理是三层防御:上游稳(固坡护沟,少给固体物)、中游拦(格宾坝、梳齿坝拦大放小,把能量分级耗掉)、下游排(排导槽把残余流顺利送进主河,不淤不堵);监测预警则以雨量阈值与次声(龙头摩擦沟床发出的低频声)做最后一道保险。拖「降雨强度」看起动门槛,拖「沟床坡度」看龙头发育;按「起动过程」看雨水如何撬动坡体,按「阵性龙头」看大石块浮在浪头,按「拦挡坝」看拦大放小,按「与洪水对比」看密度带来的冲击力差。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
