铃木偶联反应

把两个碳片段接成一根 C–C 键,是合成化学里最值钱的手艺——药物分子一大半骨架靠它焊出来,而干这活最多的催化剂是铃木偶联,三位先驱因此分享 2010 年诺贝尔化学奖。催化循环是一支三步舞:第一步氧化加成,Pd(0) 插进芳基溴的 C–Br 键,变成 Ar–Pd(II)–Br,钯从 0 价升到 +2 价;第二步转金属,碱先把苯硼酸的硼酸基去质子化活化,芳基才肯从硼「过户」到钯上,得到 Ar–Pd(II)–Ar;第三步还原消除,两个芳基在钯上牵手成联芳烃,Pd(0) 再生,回到起点接下一轮。碱是隐形功臣:既活化硼酸又中和副产物 HBr,碱量不足,循环就卡在转金属一步,产率立刻趴下。它碾压前辈格氏试剂的地方在「脾气好」:格氏对水与氧赶尽杀绝,要无水乙醚加氮气保护,一滴水闯入就当场报废;铃木却在空气里、甚至水里都能跑,副产物只有无毒的硼酸和盐——制药厂敢把它搬上万吨生产线,沙坦类降压药、抗肿瘤药都有它焊的键,材料厂用它焊 OLED 共轭骨架。拖「碱量」看循环顺畅还是卡壳,拖「温度」看反应快慢;按「催化循环」看三步舞全程,按「碱的作用」看去质子化与中和,按「与格氏对比」看一滴水终结格氏试剂,按「工业规模」看反应釜批量出活。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
