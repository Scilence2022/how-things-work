生长素极性运输

生长素 IAA 在茎尖合成,可它自己不会走路:细胞壁 pH≈5.5 把 IAA(pKa 4.75)质子化成中性的 IAAH,顺着脂双层就溜进细胞;细胞质 pH≈7 又把它拆成带负电的 IAA⁻,再穿不出膜——进出口不对称,离场只剩一条路:PIN1 外排蛋白。而 PIN 长在哪一侧膜上,单行道就通向哪一侧:茎里 PIN1 齐刷刷定位在细胞底膜,生长素便一个细胞接力一个细胞,从形态学上端流向形态学下端,速度约 10 mm/h(胚芽鞘,示意);把茎段倒过来插,流向也不反转——方向不认重力,只认 PIN 的朝向。单侧光一来,phototropin 感光并触发 PIN 的囊泡循环改道,背光侧膜上 PIN 加密,IAA 汇向背光侧,浓度抬到向光侧的 1.5~2 倍;高浓度一侧 H⁺-ATP 酶开足、细胞壁酸化、expansin 松开壁内氢键,背光侧细胞纵向伸长更快——茎不是被拉向光,是被背光侧推进光里。顶芽的下行流还有一层副作用:路过叶腋时把侧芽按在原地(顶端优势,10⁻⁵ M 量级即可,示意),再拉来 strigolactone 补刀——打顶断流,侧芽几天内解禁萌发,灌木与茶树的修剪术全靠这条原理。失效模式同样干脆:NPA 卡死 PIN,单行道瘫痪,生长素原地堆积、茎不弯、下段断粮;除草剂 2,4-D 则反向钻空子,让生长素信号失控、植物疯长脱水利衰竭而死。拖「合成速率/单侧光强/PIN 效率」三个滑杆,按「极性运输/单侧光/顶端优势/NPA 失效」四幕,按「打顶」看侧芽解禁,「光向」按钮把太阳搬到另一侧看茎反着弯。3D 交互演示 · 拖动旋转 / 滚轮缩放 · 空格播放/暂停 - 场景要点: 台面中央立着六节薄壁细胞串成的幼茎,顶芽是一小簇分生组织,第 3 节旁趴着一个休眠侧芽;每节细胞的底膜嵌着一排发光 PIN1(绿色),顶膜与侧膜的 PIN 平时熄暗。极性运输模式里金色 IAA 粒子从顶芽注入、在细胞里布朗乱撞、被底膜 PIN 一层层放下去;单侧光模式里太阳移到一侧,背光侧膜上的 PIN 点亮并迁移,粒子贴着背光壁堆出金色高浓度柱,上段随之缓缓弯向光源;顶端优势模式按「打顶」,顶芽熄灭、下行流断流,侧芽几秒内萌发伸展;NPA 失效模式里全部 PIN 变灰锁死,粒子穿不过膜、在原位堆积发红,运输速度归零。
