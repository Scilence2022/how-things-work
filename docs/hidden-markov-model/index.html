隐马尔可夫模型

有些系统的真相看不见,只能看见它扔出来的线索——天气是隐的,你朋友的行动(散步/购物/打扫)是显的;隐马尔可夫模型把这类「隔着毛玻璃猜状态」形式化:状态按马尔可夫链转移(下一状态只依赖当前),每个状态按自己的概率分布发出观测;围绕它有三个经典问题各有算法:评估——前向算法 O(N²T) 算出「这条观测序列出现」的概率;解码——Viterbi 算法用动态规划从 N^T 条状态路径里高效挑出最可能的一条(记录每步最优、最后回溯);学习——观测序列只有输出没有标注时,鲍姆-韦尔奇(EM 的前身)交替估计状态期望与重估转移/发射参数直到收敛;这套机器统治了语音识别三十年(音素作为隐状态),也是基因序列找编码区、拼音输入法整句转换、金融 regime 切换检测的第一代主力——直到深度学习接管,但「隐状态+发射」的思考方式已经渗进整个序列建模。拖「转移概率」看隐状态的黏性,拖「观测噪声」看线索变得含糊;按「生成观测」让天气暗中掷骰子,按「前向评估」看概率格逐列点亮,按「Viterbi 解码」看红线回溯最优路径,按「Baum-Welch 学习」看热图迭代收敛。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
