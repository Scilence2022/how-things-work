链喷泉

把一串珠链放进高杯,拎出一端让它垂落,链条不会乖乖贴着杯沿滑下来,而是先向上拱起一段违反直觉的「喷泉」,悬空段最高能高出杯口十几厘米。2014 年剑桥的 Biggins 与 Warner 给出解释:链条不是被「拖拽」出杯子的,而是被「发射」出去的——每节链环被拉起时,它的另一端会顶在杯里的链堆上发生一次小「踢击」,链堆给它一个向下的反冲,牛顿第三定律的另一半就把离杯的链段向上推;等效效果是链条离杯时自带向上的初速度,重力还没来得及把它压弯,它已经冲出一道抛物拱——拱顶高度约等于链速的平方除以两倍重力加速度,所以杯口越高、链速越快,拱就拱得越高。这套「从静止源发射」的图像还能反过来用:金属链落到地面时,链堆给落段的反冲会让下落端比自由落体更快,「下落的链条、秤的读数超过总重」这道百年悖论与喷泉同源;慢放与数值模拟都证实了踢击模型,它的工程回声藏在缆索系统与太空电梯的释放动力学里。拖「释放高度」看杯口越高链速越快、拱顶随之升高,拖「时间缩放」看慢放下链环一节节被踢出杯口;按「完整下落」看从垂落到稳态喷泉的全过程,按「踢击反冲」看杯内链堆闪红反冲的特写,按「无踢击对照」看拱顶消失、链条贴沿而下,按「参数实验」看释放高度连续扫描时拱顶的变化。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
