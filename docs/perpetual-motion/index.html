永动机:永远差一步的账本

八百年来最执着的发明,全部败在两条定律上。第一类永动机想凭空造能,撞死在热力学第一定律:重心偏置轮(Bhaskara 轮,1150 年)每侧力矩看似不等,实为对称配置力矩和为零,摩擦让它必然停摆;磁力斜面让钢球被磁铁吸上坡、坠洞回落,败在保守场——沿闭合路径做功为零,碰撞还偷走动能。第二类永动机想从单一热源吸热全变功,撞死在开尔文表述:不可能从单一热源取热使之完全变为有用功而不产生其他影响;麦克斯韦妖想靠信息分拣翻盘,兰道尔原理收走擦除记忆的能耗——每比特至少 kT·ln2。毛细陷阱更冤:把水抽上去的是表面张力,在管口按住不放的也是它。本页把五台著名设计在 3D 里转起来,逐台查账:输入恒为 0、输出恒为 0、损耗只增不减,转速衰减、当场停摆,每台挂着「违反哪条定律」的判词。拖动「摩擦系数」「初转速」看停得更快或更慢;按「四台巡游」看完整审计,或逐台按下「重心轮查账」「磁力斜面查账」「毛细陷阱」亲自过堂。3D 交互演示 · 拖动旋转 / 滚轮缩放 · 空格播放/暂停
