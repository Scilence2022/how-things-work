转子流量计

转子流量计是流体仪表里最老实的一只:一根上大下小的锥形玻璃管、一颗悬浮在流束里的浮子、管壁上一条刻度,构成了 1908 年 Karl Küppers 专利以来的经典测法,「转子」之名来自浮子常被流体带着自旋。它的全部奥妙是一句话——浮子把压差钉成常数:浮子受重力、浮力与向上的拖曳力,平衡时 Cd·½ρv²·A_f=(ρf−ρ)gV_f,于是浮子两侧压差 Δp=(ρf−ρ)gV_f/A_f 只由密度与几何决定(钢浮子+水约 450 Pa),与流量完全无关;环隙流速 v=√(2Δp/(Cd·ρ))≈1 m/s 也与流量无关。流量增大时,流体唯一的扩容办法是把环隙撑宽:浮子被顶到管径更大处,A_ann(h)=π(R(h)²−rf²) 随高度增大,直到 v·A_ann 恰好等于新流量——浮子高度就是流量直读,锥管(锥度约 1:30,示意)保证 A_ann 随高度近线性增长,刻度因此近乎均匀。浮子密度是量程旋钮:Q∝A_ann·√((ρf−ρ)/ρ),PTFE 浮子(2200 kg/m³)的量程只有钢(7900)的 42%,钽(16600)放大 1.5 倍;测气体时浮力项几乎消失、环隙流速冲上 ~30 m/s,同浮子量程放大一个量级,所以气表要配重浮子。浮子形状决定黏度敏感度:锐边浮子的 Cd 在 Re≳50 后几乎平直,黏度从 1 涨到 80 mPa·s 读数只偏 ~1%;球形浮子要 Re≳2000 才平直,黏液里 Cd 翻倍、环隙流速下降,同一真实流量浮子漂得更高,按水标定刻度读会虚高 ~25%(示意)。失效三则:没装正——倾斜 10° 浮子贴壁摩擦,读数偏低约 2%/°;浮子挂污——沉积物改变有效密度与锐边,零点量程双漂;流量低于最小可测——浮子压在管底纹丝不动,读数恒 0 但不代表没流。典型量程比 10:1、精度 ±1~2% FS;玻璃管直读,金属管款用磁耦合把浮子位置远传出去。拖「流量/浮子密度/黏度/倾角」改工况;按「恒压差扫流」看力箭头与高度联动,按「换浮子对照」「黏度失效」「倾斜失准」「脏污浮子」看四种对照与失效。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停 - 场景要点: 台架上垂直立着一支剖视锥形玻璃管,下端进流接管带截止阀手轮、上端出流接管,管背衬一条刻度尺(0~100% FS),管内一颗浮子悬浮在环形流束中,重力/浮力/拖曳力三支箭头钉在浮子上;青色粒子从管底涌入,在浮子高度被挤压进狭窄环隙、明显加速,过浮子后重新扩容减速——环隙流速恒定而外围流速随流量涨落。恒压差扫流模式里流量三角波往复,浮子跟着升降、Δp 读数纹丝不动;换浮子对照里密度在 PTFE/钢/钽之间切换,同一流量下平衡高度大挪移、量程刻度跟着重标;黏度失效把流体换到 80 mPa·s 重油,球形浮子虚高、锐边浮子稳如老狗;倾斜失准把台架压斜 10°,浮子贴壁、红色警告亮起;脏污浮子在浮子腰上挂一圈棕色垢环,读数整体下沉。
