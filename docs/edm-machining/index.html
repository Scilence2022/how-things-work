电火花加工:用火花蚀掉最硬的钢

车铣啃不动的淬硬钢,电火花加工却能轻松成型——它根本不靠力,而是靠电。工具电极与工件一起浸在工作液(煤油或去离子水)里,伺服系统把两者间隙稳在 10-50 μm;每个微秒级脉冲(脉宽 1-2000 μs、峰值电流 1-100 A)都在间隙最薄处击穿液体,拉出一条瞬时 8000-12000 °C 的火花放电通道,局部金属瞬间熔化汽化;脉冲结束气泡爆裂,加上工作液冲刷,把熔融金属珠整锅抛进液体,工件表面留下微米级蚀坑。放电频率可达每秒数十万次,亿万微坑层层累积成所需型腔。硬度在这里毫无意义,唯一门槛是导电——淬硬钢、硬质合金都能加工,这是它对切削加工的碾压点。工作液身兼四职:平时绝缘、击穿后冷却压缩通道、冲走蚀除物、消电离复原。极性有讲究:短脉冲(脉宽小于约 50 μs)时工件接正极蚀除量更大;重铸层只有几微米厚。伺服一旦检测到短路立即回退,绝不硬顶。线切割是它的变体:移动的钼丝/黄铜丝做电极,能切出任意轮廓。典型指标:表面粗糙度 Ra 0.1-10 μm,去除率 mm³/min 量级。演示里看电极逼近、火花在最薄点爆闪、蚀坑累积成腔;拉高峰值电流看蚀坑变大、表面变粗;按「短路回退」看伺服急退;切「线切割模式」看钼丝切缝贯通落料。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
