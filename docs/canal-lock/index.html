船闸 · 用一连串小落差代替一堵大坝

连通器原理抬船过坝:闸室 + 上下游人字门 + 输水廊道阀门,过闸只需「关门-调水-开门」四步。下行先关上门,开下泄阀把闸室水位放到下游——单级落差 10-45 m,三峡五级船闸总落差 113 m、每级约 23 m,巴拿马三级总提升 26 m;水位齐平后人字门才能开启。人字门两扇合掌成指向上游的「三铰拱」,上游水压把门缝压得越紧——水压自密封,无需铰链抗压,拱推力沿闸墙轴线传入墙体。充泄水 8-15 min,廊道出口消能盖板把高速水流打散,防系缆船受冲(缆绳张力须 <10 t)。每过闸一次耗一腔水 V=A×ΔH,三峡单次约 22 万 m³;省水池系统(3-5 池)回收约 60% 水量;巴拿马闸室 305×33.5 m 靠淡水湖运行,省水是命根子。本质是:连通器抬船、三铰拱水压自密封、阀门时序调度。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
