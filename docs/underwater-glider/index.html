水下滑翔机:不用螺旋桨横渡大洋

水下滑翔机是大海里最慢的潜航器,也是续航最长的:它干脆没有螺旋桨,靠改变自己的净浮力前进。外油囊充油,排水体积变大而总质量不变,浮力转正,机体比水轻;放油则变重——阿基米德定律成了发动机。配重块前后移动调俯仰角:『比水重 + 低头』斜向下滑,『比水轻 + 抬头』斜向上滑,锯齿状剖面一路横穿大洋。它像滑翔机不像船:不向后推水,而是把浮力势能当作滑翔机的高度,机翼把垂直运动折算成前进。代价是慢:典型航速只有 0.3-0.5 m/s(0.6-1 kn),滑翔角 20-30°,一个 200-1000 m 的剖面要花 3-9 小时;回报是省:推进功率只要数瓦,而同尺度的 AUV 螺旋桨要千瓦,一罐电池足以续航 3000-6000 km、海上数月到一年。它只在上浮冒头时伸出天线,用 GPS/卫星定位并回传数据,其余时间完全沉默。Seaglider、Slocum 与 6000 m 级深海滑翔机正在 Argo 类观测网服役,源源不断送回温盐剖面——气候研究最基础的口粮。拖动「净浮力」看滑翔角变缓变陡,拖「俯仰配平」找最省力的姿态;按「完整剖面」看油囊充放油、俯仰翻转与锯齿轨迹;按「滑翔角优化」与「6000 m 深潜」分别体验最平缓滑翔与深海剖面——能量条全程停在『瓦』级。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
