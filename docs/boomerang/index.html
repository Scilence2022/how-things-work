回旋镖

回旋镖是被扔上天的一排旋转机翼:两叶(或三叶)V 形排列,截面像机翼一样上凸下平,出手后高速自转,每叶各自产生升力;奥妙在两叶看到的相对气流不同——出手转速约 8–12 转/s,叶尖线速 v_tip=ω·r 可达 40–50 m/s,前进侧叶尖顺着飞行方向,合速约 v+v_tip,后退侧相减只剩 v−v_tip,升力随速度平方放大,前进侧明显更壮;这道不对称升力合成净力矩 τ,而高速自旋给了镖很大的角动量 L,力矩扳不倒它,只能按 τ=dL/dt 让镖盘绕竖直轴缓慢进晚会——升力方向持续偏转,飞行路径弯成半径约 10–20 m 的圆弧,进晚会速率 Ω_p=τ/L,自旋越快弯得越缓;能量账同样精巧:阻力按线性与平方两档花掉动能,升力倾角的水平分量充当向心力,后半程前进速度耗尽,镖靠剩余自旋滑翔下飘,好镖回旋完成时几乎悬停落掌;出手要领三条:镖面与竖直方向夹 15–30°(掷一枚竖着的盘子,而非飞盘)、俯仰抬约 20°、大力甩腕给自旋,平甩的飞盘式只会直飞不回;别被电影骗了:澳大利亚原住民的主力是重而直飞的狩猎镖,能掷出上百米,会回家的返回镖较轻,多用于游戏与仪式;自旋不足会弯不过来,出手太平会爬升失速,风太大回路会被吹变形——拖「自旋速率」「出手倾角」亲手复现翻车;按「飞行回路」看一圈回家,按「进晚会特写」看 L 与 τ 如何共舞,按「出手要领」对比三种出手,按「失效:转速不足」看直坠出界。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
