本体感觉:肌梭测长度、腱器官护张力

闭眼把指尖送到鼻尖,靠的不是视觉,而是肌肉里的两套传感器:肌梭与腱器官。肌梭是埋在梭外肌纤维之间的纺锤形小囊,与肌腹「并联」——肌肉被拉长它必被拉长,内含 3-10 根梭内肌纤维(核袋与核链);Ia 初级末梢以螺旋绕住核袋,对约 0.5 mm 的伸长尤其是牵拉速度都敏感,静息放电 ~50 Hz,快速牵张时冲到 200-350 Hz;II 次级末梢只在核链上报静态长度。腱器官则卡在肌纤维与肌腱交界处,与肌肉「串联」,Ib 末梢编在胶原束之间,整肌张力要数百牛顿才明显放电(10³-10⁴ N 量级强放电),专报主动张力。牵拉肌肉,Ia 冲动以 70-120 m/s 进入脊髓后根,与 α 运动神经元单突触直连(延搁 ~1 ms),约 50 ms 肌肉回弹——膝跳反射;张力过载时 Ib 经抑制性中间神经元压制 α,~100 ms 反牵张反射让肌肉松手保腱。γ 运动神经元与 α 共激活,随时把梭内纤维两极绷紧「校零」,否则主动缩短时肌梭松弛失聪——这就是闭眼拿杯子不出错的秘密;这些信号上传小脑与顶叶后,肩肘关节盲指复算误差只有 1-2°。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
