密立根油滴实验

电子带多少电?1909 年密立根的答案是:拿一滴油跟它对峙。喷雾器把油滴喷进平行板电容器,油滴带电(摩擦或 X 射线电离空气所赐),在重力下先做终端速度下落——斯托克斯阻力按半径算,量出下落速度就锁定了油滴的质量;再打开电场,微调电压让油滴悬停不动,此刻电场力恰好压平重力,qE = mg,一带入就得到油滴携带的总电荷。密立根反复测了几千滴,把电压、下落速度、悬停电压全部记录,发现所有电荷都是 1.59×10⁻¹⁹ C 的整数倍——1909-1913 年间他发表了 58 滴的完整数据,电子电荷 e 与质量 m(配合荷质比)就此定案,1923 年诺贝尔奖。这场实验的美在于把「量子」变成了肉眼可见的演出:整数的倍数列在对数纸上排成等距阶梯;但争议随之而来:历史学者后来的审读发现密立根发表时筛除了部分数据,而他在论文里声称「全部数据都在」——科学史上关于数据伦理最著名的案例之一。今天油滴实验仍在大学物理课里运转,不过是作为标定空气尘埃粒子的经典手法。拖「板电压」看油滴起落,拖「油滴选择」换一颗;按「悬停校准」看 q=mgd/V 现场解出,按「X 射线脉冲」看电荷跳台阶,按「数据表回放」翻 1909 年的记录本。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
