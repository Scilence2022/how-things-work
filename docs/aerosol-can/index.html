气雾罐

气雾罐能在任何角度喷出均匀的雾,靠的不是压缩空气,而是一锅「两相平衡」:罐里装着约九成有效成分液体和一成液化推进剂——丙烷、丁烷或二甲醚,1970 年代前的氟利昂已为臭氧层退役。密闭后部分推进剂气化,在液面上方建立蒸气压;关键是只要还剩一滴液化气,这个压强就只由温度决定——气液相平衡,不随罐子空了多少而变,所以第一喷和最后一喷同样有力。按下一体阀:阀杆下压打开通道,蒸气压把罐底液体沿浸没管顶上来,在喷嘴小孔处骤然降压,被高速气流剪切撕成微米级雾锥——压差越大,雾越细。安全账本有两页:20 °C 时罐内约 2–4 bar,扔进火里温度冲到 60 °C,饱和蒸气压翻倍,罐体爆破是真实的「爆米花」;液体烧完后罐里只剩蒸气,压强才随每一次喷发衰减——「罐子不响但喷不出东西」,说明只剩气了。压缩空气款是反面教材:没有液化气储备,压强随用随跌,最后一喷软得像叹气;而倒着喷时浸没管离开液面,出来的只有推进剂白雾——清洁电路板的「气吹」正是利用这一点。拖「罐体温度」看蒸气压如何随温度爬坡,拖「剩余液体量」看液面与喷次余额;按「按压喷雾」看阀杆开合与雾锥成形,按「温度与压强」看压强表跟着温度走,按「最后一喷」看液面见底后压强掉头,按「倒置喷气」看只有白雾没有液体。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
