彭罗斯过程

1969 年彭罗斯指出,旋转黑洞有一份「可以取走」的财产:克尔黑洞的视界外有一层叫能层(ergosphere)的区域,参考系拖曳在其中强迫一切物体随黑洞同向转动——连静止悬停都做不到;在能层里把一艘飞船一分为二:让半块沿「负能量轨道」落入黑洞(在远方的观察者看来它带着负机械能),黑洞吞下它之后质量与自转角动量双双下降,而按能量守恒,飞出的另一半获得等额增益——净利润全部来自黑洞的自转能,极端克尔黑洞理论上最多可被抽走约 29% 的质能(不旋转的史瓦西黑洞一分都取不走);霍金面积定理并不因此破防:每次抽能,视界面积仍然只增不减;宇宙里真有这台机器的电机版:Blandford-Znajek 机制让磁场线在能层里被拖曳缠绕,把自转能沿磁力线抽出来,喂饱类星体那上万光年长的相对论喷流——星系中心的黑洞自转,就是这样点亮了宇宙最亮的灯。拖「黑洞自旋」看能层厚度与可抽取份额,拖「分裂质量比」看两半碎片的收益分配;按「能层解剖」看拖曳流线,按「分裂过程」看负能碎片坠入,按「自旋收支」看黑洞变慢变轻,按「BZ 喷流」看磁力线点亮双向喷流。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
