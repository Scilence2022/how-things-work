锡焊与助焊剂

锡焊是人类用得最久的连接术,也最反直觉:母材从头到尾不熔化,强度全靠界面处一层 1–3 μm 的金属间化合物。古罗马人用铅锡合金接管子,今天一块手机主板上有上千个 SMT 焊点,原理没变——润湿。液态焊料要在铜面摊开,得满足杨氏方程 cosθ=(γsv−γsl)/γlv,接触角 θ<90° 才算润湿,θ 越小铺展越充分;但铜面在空气中放几小时就会长出几纳米厚的氧化膜,焊料一上去就缩成球滚走,于是助焊剂登场干三件事:松香酸或卤素活化剂在约 200 °C 活化,把氧化膜溶解剥掉;把焊料表面张力降下来;再铺开盖住界面隔氧。焊点真正的强度来源不是焊料本身,而是界面长出的 IMC——Cu6Sn5 与 Cu3Sn,像一层「分子铆钉」;回流时焊点要加热到高出熔点 20–40 °C、保温 30–60 s 正合适,过热或太久 IMC 长过 3 μm 就变脆,一敲整片脱落。传统 Sn63Pb37 共晶焊料 183 °C 熔化、液固一步到位;2006 年 RoHS 生效后主流换成 SAC305,熔点 217 °C,润湿更差、更吃强活性助焊剂,纯锡镀层还埋下锡须隐患——1998 年银河四号卫星就因锡须短路而失联。焊坏的姿势也很经典:烙铁温度不够或撤热太早,焊料没润湿就凝固,堆成灰渣色小丘,这是冷焊/虚焊,接触电阻大、轻碰就断;送锡太多会桥连短路,撤铁太慢又拉出尖刺。拖「烙铁温度」看过热度与冷焊,拖「助焊剂活性」看氧化膜与润湿角;按「润湿铺展」看焊料如何在铜面摊开,按「IMC 界面」看 Cu6Sn5 如何长出来,按「冷焊对比」看虚焊点的灰渣小丘,按「无铅挑战」看 SAC305 为什么更难伺候。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
