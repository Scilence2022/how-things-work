Delaunay 三角剖分:连点成网的最优解

把一堆散点连成三角形网格,连法多到天文数字,而坏的连法布满细长三角形:插值把邻域拉歪,有限元刚度矩阵病态,渲染表面撕裂。1934 年苏联数学家 Boris Delaunay 给出好网格的判据:每个三角形的外接圆内部不含任何其他点——空圆准则,它等价于在所有连法中最大化最小角,数值稳定性最好。怎么建?增量插入(Bowyer–Watson):新点落下,凡外接圆被它入侵的三角形当场塌陷,空腔边界与新点重连成星形,随机插入序下期望 O(n log n);四点共圆出现平局时,Lawson 翻转交换凸四边形对角线即可修复。它与 Voronoi 图互为对偶:相邻领地共边的两点连起来就是 Delaunay 边,三角形外心正是对偶顶点。按「增量插入全流程」看新点下落、空圆一闪、星形重连;按「边翻转修复」先故意把好对角线全换成坏的,红色细长三角形泛滥,再看翻转一次次把平均最小角顶回去;拖「点数」重建网格,把「点扰动」拉到 0 体会规则格点的共圆退化;「Voronoi 对偶」把对偶图抬到空中对照。地形 TIN、有限元前处理、自然邻域插值、地图渲染与三维重建,全是它的工地。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
