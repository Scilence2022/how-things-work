LLM 采样:温度如何把 logits 变成词

语言模型每步给整张词表(数万到十几万维)打分输出 logits,softmax p_i=exp(z_i/T)/Σexp(z_j/T) 把分数变成概率:T<1 变尖、T>1 摊平、T→0 退化为贪心 argmax(容易死循环);top-p(nucleus)取累计概率 ≥p 的最小候选集(典型 0.9),把长尾胡话一刀切掉后重新归一;top-k 固定保留 k 个;重复惩罚把已出现 token 的正 logit 除以 α;采样=掷一个均匀随机数 u,落在累积分布哪一段就选哪个 token;每个被选中 token 的惊讶度=−log₂p,整句平均即交叉熵,困惑度=2^平均惊讶度。演示:20 个候选的概率条随温度实时重排、掷骰落点采样、T=0 死循环对照、重复惩罚破环、熵与困惑度仪表 · 3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
