颗粒捕捉器:炭烟的陶瓷迷宫

柴油机是扩散燃烧:燃油喷进气缸来不及与空气混匀,富油区高温缺氧,天然产生炭烟——碳核上吸附着有机物与硫酸盐,几十到几百纳米。DPF 颗粒捕捉器是壁流式蜂窝陶瓷(堇青石或碳化硅,200–300 cpsi 蜂窝孔,壁厚 0.3–0.5 mm,壁内微孔约十微米):相邻孔道一端封堵、另一端敞开,交替排列——废气没有直路,被迫穿过这面多孔壁,颗粒撞在壁上被拦,过滤效率大于 95%(质量计);气体走了「墙」,炭烟留下了。炭越积越多,背压升高、油耗升、动力降,必须定期再生:被动再生——上游 DOC 把 NO 氧化成 NO₂,C+2NO₂→CO₂+2NO 在 250–450 °C 持续慢烧;主动再生——排温不够就后喷燃油或推迟喷射,把载体烧到 550–650 °C,C+O₂ 放热链式推进,10–30 分钟,通常每几百公里一次。温度是双刃剑:低于 550 烧不动,超过 800 载体烧结甚至烧熔。灰分(机油添加剂的钙/锌/磷与磨损金属)不可燃,慢慢占容——几万公里后要拆下来灰洗;再生失败、长期短途会堵死限扭「跛行」。与汽油机的三元催化 TWC、柴油机的 SCR 尿素共同构成排放后处理三件套;满载炭量 5–8 g/L,再生额外燃耗 2–4%。演示里拖「排温」看被动/主动再生的切换,孔道积炭变暗、背压表爬升;点火后看温度前锋扫过、炭烧成 CO₂、背压回落;按「灰分累积」「再生失败」看长期后果;勾「三件套全景」看 DOC→DPF→SCR 流水线。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
