秘书问题与最优停止

你要招一名秘书,100 份申请一个个来,见面即决策:当场录用或永别,不能回头;目标只有一个——录用到「最好的那位」的概率最大化。怎么面?面完所有人再决定不可能,最好的可能早已错过;太早定,又可能错过更好的。1960 年代给出的最优解优雅得惊人:先观察前 n/e ≈ 37% 的候选人,只记录最大值、一个都不选;之后遇到的第一个「比前面所有人都强」的,当场录用。这个策略的成功率恰好也是 1/e ≈ 36.8%——注意这不是及格率,而是任何策略都无法逾越的天花板:在信息只能单向流动的世界里,你注定有三分之二的情况拿不到第一名。背后的数学是动态规划:设观察期 r,录用到最好的概率 P(r) = (r/n)·Σ(1/k)(k 从 r 到 n-1),求极值,当 n 很大时 r*/n → 1/e。它同样回答更日常的问题:租房看多少套再出手?相亲见多少人再定?前提是候选随机到达、你只在乎「第一名」;若规则改成「满意即好」,策略与成功率都会变。这个 1960 年的模型如今活在最优停止理论里,成了拍卖出价、资产卖出的共同骨架。拖「候选数 n」看 37% 划线,拖「观察期 r」看成功率曲线;按「单轮演示」看一条高度序列与决策点,按「成功率曲线」看 P(r) 的驼峰,按「千轮模拟」看频率收敛到 36.8%,按「全知对比」看上帝视角的差距。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
