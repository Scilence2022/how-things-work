履带行走装置

轮式车辆的死穴是接地压强:六十吨的主战坦克若把重量压在几只轮胎上,烂泥地里早趴了窝,可它碾过的地面只留下与成年人步行同量级的压痕——秘密是把重量摊到两条「自带的道路」上:两条履带接地面积约 5.2 平方米,接地压强=重量÷面积,只有 110 kPa 上下;履带板销接成闭合环,驱动轮(主动轮)并不滚地面,而像一台绞盘,把「道路」从前方卷上来铺到脚下、再从车尾收走——车上所有轮子只在履带里滚动,永远不碰泥土;前端诱导轮靠曲柄张紧机构维持垂度,中部 5 个支重轮经扭杆悬挂把车重传给履带,上支段的托带轮防止履带高速「打鞭」;到了松软地面,光靠接地面积不够,履带板上的横向履齿像船桨一样剪切土体——推力来自「剪断土」,而不是「抓住土」,下陷越深,参与剪切的土体越多;转向是履带的独门绝技:两侧履带差速,一侧停转,车体就绕这条履带画圈,一侧反转,坦克原地旋转——零转弯半径,轮式车做不到;越野的颠簸则被扭杆悬挂吸收,支重轮行程大,车身平稳。拖「车速」看履带卷绕与地面后移,拖「转向差速比」看大半径回转到原地旋转;按「直线行驶」看绞盘铺路,按「原地转向」看零半径掉头,按「软土越野」看履齿剪切与下陷,按「履带卷绕特写」凑近看驱动轮啮合。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
