骨传导

堵住双耳再哼歌,歌声依然清晰——这条路平时就在工作:声音到达耳蜗有两条路,一条是主流的气导(声波→外耳道→鼓膜→三块听小骨→耳蜗),另一条是骨导(振动直接经颅骨传进耳蜗)。骨传导耳机把这条备用路变成主路:贴在颞骨上的振子让颅骨整体微振,耳蜗里的淋巴液被直接激起行波,毛细胞照常发电位——耳道全程开放,环境音一个不落,跑步骑车时听得见身后车流;贝多芬失聪后咬住连接钢琴的木棒作曲,用的就是这条路。骨导在临床上还是鉴别诊断的钥匙:韦伯试验把震动的音叉顶在颅骨正中,单耳传导性耳聋(鼓膜或听小骨坏了)的患者会说患侧更响——患侧耳道被环境声「淹没」的干扰消失了,骨导信号反而凸出;感音性耳聋(耳蜗或听神经坏了)则健侧更响。林纳试验对比同一耳的气导与骨导:正常人气导更长,传导性耳聋反过来——两个试验一组合,病灶位置当场定位。骨导的短板在高频:颅骨是个低通滤波器,4 kHz 以上衰减明显,音乐细节打折,所以它适合通话、导航与运动场景,不适合录音师的监听。拖「音量/频率」看两条通路的响应差,拖「气导损失」模拟传导性耳聋;按「两条通路对照」看气导与骨导的并行,按「韦伯试验」看音叉偏侧,按「贝多芬模式」咬住木棒听琴。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
