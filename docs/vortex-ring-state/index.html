直升机涡环状态

直升机悬停时,旋翼往下打出一根稳定的下洗流柱,升力账本干净利落;可一旦飞行员带功率做大下降率、又几乎没有前飞速度,旋翼就会一头扎进自己刚排出的下洗里:桨尖涡来不及被带走,在桨盘外缘卷成一个环状回流——外缘的空气被重新吸上桨盘、再从中心喷下去,升力分布乱成一团,总距拉满也只换来下降率自我加剧,飞机「掉进自己制造的漩涡」,越补总距掉得越快;触发窗口有公式可查:垂直下降速度超过诱导速度的一半(Vv > ~0.5·Vi)、而前飞速度比 μ < 0.25 时最危险——功率下降区就是它的家门口;改出的正解反直觉:不是拉总距,而是前推驾驶杆获得 15–20 节以上的平飞速度,让新鲜的来流把涡环整个吹散(或干脆降总距进自转);桨尖涡环可视化、风洞与试飞数据共同画出了这张「涡环危险包线」,它被写进每一本直升机教材与每一次山地/吊挂作业的简报里。拖「下降率」看旋翼扎进自己的下洗,拖「前飞速度」看来流如何吹散涡环;按「悬停基准」看干净下洗柱,按「进入涡环」看桨尖涡卷成回流,按「危险包线」看工作点漂进红区,按「改出动作」看前推杆脱困。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
