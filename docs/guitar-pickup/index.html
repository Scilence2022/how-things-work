电吉他拾音器

电吉他不插电时声音干瘪,插电后的全部灵魂来自一排磁铁加一圈线:拾音器的磁极把钢弦局部磁化——琴弦本身成了一块磁铁;弦振动时,它在磁极上方的位置周期性摆动,穿过线圈的磁通随之涨落,法拉第定律当场变现:线圈两端感应出几毫伏到几百毫伏的交变电压,频率就是弦的振动频率,谐波成分也是弦的谐波成分——拾音器不是麦克风,它直接读出弦的力学振动,不采空气。单线圈的烦恼是嗡声:一圈几千匝的线就是一台天线,50/60 Hz 的电网 hum 被原样收进来;1955 年 Gibson 的 Seth Lover 给出双线圈方案:两组线圈反向绕、磁极反向排(humbucker),电网 hum 在两圈里感应出同向电流、相减归零,而弦的信号因磁极反向感应出反向电流、相减后反而相加——噪声成对出现被抵消,信号成对相反而被保留,一石二鸟。拾音位置还是音色旋钮之外的另一颗旋钮:琴桥端靠近弦的固定端,高次谐波节点多、音色冲而亮;琴颈端靠近振动腹,基频强、音色暖——同一个吉他手换一次挡位等于换了半个音色。拖「弦振幅」看磁通涨落,拖「拾音位置」听音色迁移;按「单/双线圈对照」看 hum 相消,按「磁场慢放」看弦如何 squeeze 磁感线,按「谐波节点」看位置为何改音色。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
