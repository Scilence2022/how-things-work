1917 年维尔南把密码学推到前无古人的高度:密钥与明文等长、真随机、只用一次,逐位异或——密文里从此不含任何明文的统计痕迹,香农 1949 年证明这是数学意义上唯一的「完美保密」:敌人烧穿全部算力,得到的也只是「明文可能是任何等长文本」的均匀分布。但完美有三张账单:真随机数在计算机时代极难量产,伪随机数生成器的规律一用就破功;与明文等长的密钥必须提前安全送到对方手里,分发和保管的通道本身就先成为漏洞;最致命的是重用——两条密文一异或,密钥当场抵消,剩下的 P1⊕P2 会在字母频率分析下裸奔,二战后美军「维诺纳」计划正是抓住苏联密码本误重用,破出绵延数年的情报流;冷战热线靠信使手递密钥本,今天它借量子密钥分发翻案:窃听必留痕迹的送钥通道,让「先囤密文等量子计算机」的对手无米下锅。拖「密钥重用次数」看密钥抵消如何泄底,拖「密钥长度」看截取位数对破译进度的影响;按「加解密演示」看三条位流逐位异或,按「重用攻破」看频率柱状图从密文里长出语言残影,按「真随机 vs PRNG」看两种密钥热图的规律差异,按「分发难题」看信使与量子信道对窃听者的攻防。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
