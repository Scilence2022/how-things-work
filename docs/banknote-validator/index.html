验钞机

银行点钞机哗哗过钞的每一秒,机器已经给每张钞票考了四场物理:钞票以 0.5–1.5 m/s 穿过检测通道,传感器每秒采集几百行数据,荧光、磁性、红外、光学几何几种效应同时打分,任何一项不过关,电机立刻停机反转、报警吐钞——验钞机的本质,是一条多传感器融合的传送带安检线。第一关紫外:真钞用棉短绒掺木浆抄造,不含荧光增白剂,365 nm 紫外灯下整张暗沉;办公纸为显白普遍加了增白剂,紫外下发亮蓝白光,荧光强度是第一道粗筛;真钞还藏着无色荧光面额数字与随机荧光纤维,靠斯托克斯位移发光:吸收 365 nm、发射 420–450 nm 蓝光。第二关磁性:部分油墨掺氧化铁微粉,技术源自支票 MICR 磁码,人像与冠字号码局部带磁,磁头阵列按位置记录磁通变化再与模板比对——这一关看的不是「有没有磁」,而是「哪一段有磁」。第三关红外:不同油墨对 850–950 nm 近红外吸收不同,真钞人像边缘与面额区在红外图像里「消失」,高仿币最常栽在这里。第四关光学几何:透射光照出水印的厚薄浮雕,安全线、对印、光变油墨逐一核对,对辊测厚(纸厚约 0.1 mm)专抓洗改面额。四路分数加权成置信度,阈值在拒真与纳假之间谈判:GB 16999-2010 要求 A 类机检出率不低于 95%,而误报主因恰是磨损旧钞。这还是一场军备竞赛:雕版高仿逼近印制工艺,真钞用动感光变镂空安全线反击——伪钞追一种效应,真钞就加一种。拖「传送速度」看采样与误报的矛盾,拖「伪钞仿真度」看它能骗过几关;按「荧光关」「红外·水印」「高仿挑战」看各道关卡如何排雷。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
