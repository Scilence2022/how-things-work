拉格朗日插值

在纸上钉下 n+1 个点,能穿过它们的 ≤n 次多项式永远只有一条——不多,也不少。这就是拉格朗日插值,1795 年由拉格朗日写进讲义(华林 1779 年、欧拉 1783 年其实早已写出等价公式)。它的构造像变戏法:为每个节点造一个基函数 ℓᵢ(x)=Πⱼ≠ᵢ(x−xⱼ)/(xᵢ−xⱼ),分子分母来自同一组乘法,ℓᵢ 便在自己节点取 1、在其余节点全是 0;乘上 yᵢ 相加得 P(x)=Σyᵢℓᵢ(x),自动穿过全部节点,连方程组都不必解。唯一性一行证完:两条都过这 n+1 个点的 ≤n 次多项式相减,差有 n+1 个根但次数至多 n,只能恒为零。这门手艺就藏在你口袋里:CD、DVD 与二维码的 Reed-Solomon 纠错码在 GF(2⁸) 有限域上做拉格朗日插值,划痕擦掉一批字节照样还原;Shamir 1979 年的秘密共享把秘密编成一条直线的截距,凑不齐 k 份碎片就一无所知;数值积分的高斯求积权重同样由这些基函数生成。但它有一桩著名恶疾——Runge 现象:对 1/(1+25x²) 用等距节点插值,次数越高、端部振荡越凶,n=10(9 次)时边缘误差 0.30,已是函数谷底 0.038 的近 8 倍;n=14 时冲到 1.07、放大约 28 倍,16 个节点时约 2.1、55 倍,再往上误差发散到无穷。病根不在舍入误差,而在等距节点两端太稀:Lebesgue 常数指数增长,范德蒙矩阵条件数在 n=14 已破 10⁶,数值求解同样病入膏肓。药方有二:其一切比雪夫节点 cos(iπ/(n−1)) 两端密、中间疏,同样 14 个节点把端部误差压到 0.15,并随次数指数收敛;其二工程上更常用的分段三次样条,每段永不超 3 次、接缝对齐到二阶导,同样 14 个节点误差只有 0.05,飞机翼线与车身曲面全靠它画成。拖「节点数」看曲线随次数起伏,拖「节点分布」看等距滑向切比雪夫;按「基函数装配」看 ℓᵢ 逐个亮起拼出 P(x),按「Runge 恶魔」看等距高次端部爆炸,按「切比雪夫救场」看重排节点压住振荡,按「样条对比」看分段低次如何收场。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
