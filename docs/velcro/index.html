魔术贴:钩穿圈回弹卡住,撕拉声就是逐钩解锁

1941 年,瑞士工程师德·梅斯特拉尔带狗打猎,粘了一身牛蒡果,显微镜下全是细小弯钩——十余年后注册专利 VELCRO。一侧尼龙注塑成排小钩,密度约 100-300 钩/cm²,另一侧是尼龙单丝圈绒;按压时钩尖穿入圈、梁弹性回弹卡住钩颈,挂合率 70-90%。剪切方向整面数百钩同时受剪,25 mm 宽搭接可承载数 kg;而剥离时应力集中在剥离前沿,钩被逐个从圈里撬出,剥离强度仅 ~1-1.5 N/cm——每次解锁的微滑移叠成连绵「嘶啦」声。钩只能沿剥离方向退出,垂直/剪切几乎拉不开,方向性锁合被仿生学写进教科书:太空应用需涂层防月尘卡死,医疗、军服、飞机座椅常见。循环寿命 ~5,000-10,000 次 · 3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
