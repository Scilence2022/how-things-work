子弹星系团

两个星系团在三亿多年前迎头相撞,留下了一张暗物质存在的「抓拍」:1E 0657-56,昵称子弹星系团。碰撞的剧本分三条线:星系团里的星系只占质量的百分之几,它们像两群互不接触的鸟群,直接穿场而过;占普通物质大头的热气体(用 X 射线看,粉红色)却撞在了一起——气体稀薄但质量巨大,两团气体迎面相撞后像流体一样互相减速,被甩在碰撞区中间,前沿还拖出一道弓形激波;而引力透镜勾画出的质量分布(蓝色)却跑到了两边——大部分质量既不在星系里,也不在气体里,它不发光、不与气体摩擦、几乎没有阻力地穿过了对方。能这样行为的质量,正是暗物质:它只参与引力,撞不上任何东西。这张图把「暗物质是不是引力理论出错的错觉」这条退路基本堵死:如果引力理论错了,质量应该跟着发光物质(星系)或气体走;实际质量峰与两者都分离,唯一自洽的解释是那里存在一团不发光的物质,先穿过去了。子弹星系团不是孤例:此后十几年又发现十余对正在碰撞的星系团呈现同样的「气体与质量分离」。拖「碰撞进度」看三路分合,拖「暗物质占比」看质量峰位置;按「对撞过程」看气体被刹住、暗物质穿过,按「透镜质量图」看引力如何扭曲背景星系,按「X 射线气图」看激波锋面,按「峰移对比」看质量与光的错位。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
