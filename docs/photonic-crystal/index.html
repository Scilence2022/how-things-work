光子晶体:不用色素,用周期给光立规矩

肥皂泡的彩虹、甲虫的金属绿、欧泊的变彩、大蓝闪蝶的电蓝——这些颜色不来自任何色素,而来自亚波长尺度的折射率周期:光子晶体。布拉格条件 2d·sinθ=mλ 决定哪个波长被相干相消地反射出去,其余照常通过——被「开除」的波段形成光子带隙,好比半导体对电子的能隙。结构色有三大特征:色随视角变(彩虹色,角度一改 cosθ 就换波长)、饱和明亮(能量全进一条窄带而非靠吸收)、永不褪色(是结构不是化学)。天然欧泊是 200-300 nm 的 SiO₂ 小球按面心立方堆积;大蓝闪蝶靠树状脊的多层干涉选出 460 nm,再用 10-20% 的多尺度无序把角度依赖抹平,换来任意角度都成立的蓝。工程上,无毒结构色颜料、光子晶体光纤、永不褪色的汽车涂料与织物都已上路。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
