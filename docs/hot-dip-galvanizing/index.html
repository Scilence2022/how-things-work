热浸镀锌

防锈最便宜的方案是一条 450 °C 的锌池:除油、酸洗、助镀后的钢件整个浸进熔融锌液,铁与锌在界面上直接反应,长出一层层铁锌合金(Γ、δ、ζ 相层层相扣),提出来时外面再挂一层纯锌——这不是刷上去的漆,是长进去的冶金结合,硬度高、划不穿。锌的聪明之处在于它不靠隔离靠「牺牲」:锌比铁活泼,镀层破损露出的钢切口旁,锌作为原电池的负极率先氧化,电子源源不断喂给铁,让铁的氧化反应无从发生——一块几毫米宽的切口周围,几十微米厚的锌层能站岗十几年;这就是牺牲阳极保护的镀层版。账本也清楚:热浸镀层厚 50-150 μm,户外钢结构寿命 20-50 年,成本只有不锈钢的零头;锌液温度必须压在 480 °C 以下,超过后铁锌反应失控,合金层厚而脆,镀层一敲就掉(硅含量高的钢尤其容易「超长」,须控温并在锌液中加铝抑制)。产量最大的终点是流水线:带钢连续浸镀成的热镀锌板,撑起汽车车身与家电外壳;结构件则一锅一锅浸,护栏、铁塔、灯杆,镀完还能看到锌液冷却流淌的泪痕花。拖「浸镀时间」看合金层怎么长厚,拖「锌液温度」看反应快慢与脆层风险;按「入锅浸镀」看全程,按「镀层剖面」看五层结构,按「切口保护」看锌如何在缺口处牺牲自己,按「红锈对比」看有无镀层的命运分岔。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
