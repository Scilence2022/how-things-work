月经周期:一场激素的振荡电路

28 天月经周期不是日历,而是一台由下丘脑-垂体-卵巢轴搭成的激素振荡电路。开局 FSH 催一批卵泡发育,发育中的卵泡分泌雌激素;雌激素在低浓度时执行负反馈,压住 FSH 与 LH——这是电路的常规增益控制。但它藏着整台机器的发条:当优势卵泡把雌激素推到高浓度并持续 36-48 小时,同一个回路翻转成正反馈,LH 暴涨成峰,约在第 14 天顶破成熟卵泡——排卵。破卵之后,残壁变成黄体,分泌孕酮加雌激素:孕酮把内膜改造成可着床的分泌期「床」,同时用负反馈把 FSH/LH 死死压低,防止下一批卵泡抢跑。未受精,黄体在第 22-24 天自行退化,孕酮与雌激素塌方,子宫内膜失去支撑、剥脱出血——月经;刹车一松,FSH 解禁,下一轮振荡启动。内膜全程同步装修:增殖期在雌激素下长厚,分泌期在孕酮下储能。口服避孕药的原理就是从外部供给孕激素,把负反馈钉死在「高位」,LH 峰永不出现,不排卵,也不怀孕。内分泌系统里,这种「浓度依赖的正负反馈翻转」极其罕见,它就是周期的发条。拖动「周期日」看四条激素曲线滚动推进,把「雌激素峰值」削到阈值以下,LH 峰当场消失、排卵不再发生;或按「避孕药对照」看整台振荡器被按停。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
