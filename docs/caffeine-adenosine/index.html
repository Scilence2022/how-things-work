咖啡因:腺苷受体的占位欺骗

清醒的每个小时,腺苷都在基底前脑的账本上累加;它与 A1/A2A 受体结合,把「该困了」的信号写进觉醒回路。咖啡因不删除账本——它是竞争性拮抗剂:三环分子形状恰好卡进结合口袋却不激活受体,把信号挡在门外。口服 ~99% 吸收、约 45 min 达峰,半衰期 ~5 h(肝 CYP1A2 代谢为副黄嘌呤):早晨 8 点的 200 mg,到半夜 0 点体内还剩 ~75 mg——「下午的咖啡毁掉睡眠」是半衰期的算术,不是体质。连续饮用则迫使受体上调代偿(耐受),一旦停用,12-24 h 内腺苷不再有对手:血管舒张性头痛、倦怠持续 2-9 天。吸烟使半衰期减半,口服避孕药使其翻倍——个体差异写在代谢酶里。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
