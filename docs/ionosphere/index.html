电离层与短波天波

短波电台功率不过几百瓦,却能从北京喊到阿根廷——靠的不是绕地球爬,而是天上那面「镜子」。太阳紫外线与 X 射线把 60-500 km 的高层大气打成等离子体:电子被从原子剥下,形成 D(60-90 km,只在白天存在)、E(90-150 km)、F(150-500 km,白天裂成 F₁/F₂)三层;等离子体的关键参数是等离子体频率 f_p≈9√N_e(Hz,N_e 为电子密度/m³),低于它的电磁波会被整体推回来——频率像选门:长波碰 D 层就折返,短波 3-30 MHz 穿透 D、折返于 F,频率再高则直接穿出去进太空。于是地面波贴地爬百公里,天波却在地面与 F 层之间打水漂,一次跳跃 2000-4000 km,三跳就横跨大洋;发射仰角决定跳距,天线仰角抬高近跳、压低远跳。昼夜是短波的呼吸:D 层是吸收层,白天吃掉中波,太阳一落它瞬间消散,中波广播夜里的「台多得数不清」正是 D 层下班;而太阳耀斑会在几分钟内把 D 层吹浓,短波全频段骤哑——1859 年卡林顿事件让电报员被电弧烧伤,1989 年风暴让魁北克电网九秒崩溃。GPS 同样付电离层账:信号穿过时被延迟,双频修正就是用两个频率的时差反推总电子含量。拖「频率」看哪个层收留你,拖「当地时间」看昼夜层高变化,拖「发射角」调跳距;按「静区演示」看天波飞过头顶落在远处、近处反而收不到,按「太阳风暴」看 F 层扰动与通信中断,按「昼夜切换」看中波电波夜行千里。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
