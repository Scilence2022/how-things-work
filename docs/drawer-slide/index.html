抽屉滑轨:满伸悬空

三根 C 型冷轧钢剖面(壁厚约 1.2 mm)互相套嵌、两道闭合滚珠笼接力,把几十公斤的抽屉整个悬到柜外:滚珠在 58-62 HRC 淬硬滚道上纯滚动,等效摩擦系数只有 μ≈0.015,35 kg 满载抽拉力不过 ~5 N。但满伸是极限工况:抽屉+载荷的重心越过柜门约 200 mm,悬臂力矩 M=W·x≈70 N·m,杠杆把 ~2 倍的单侧分摊载荷压给最前排滚珠组,后组反而要向下拉住 ~1 倍——所以笼壳上下都有挡块、载荷额定值一律按满伸标定(L10=(C/P)³,载荷 +26% 寿命腰斩)。偏载 70/30 再满伸:重侧单珠 ~60 N、赫兹接触应力 ~1.5 GPa、轨端挠曲 3~5 mm,歪斜楔紧就会「抽到一半卡死」。液压阻尼接管最后 ~80 mm,把 0.3 m/s 的回弹节流成缓合;快拆拨杆抬起 ~4 mm 越过限位,抽屉连内轨整套卸下。拖「行程/载荷/偏载/前后位」看载荷路径与挠曲实时重排,按「滚珠循环/满伸悬臂/阻尼回弹/快拆/无珠滑动」对照——抽走滚珠,μ 跳到 0.15、拉力十倍、一抽一顿黏滑。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
