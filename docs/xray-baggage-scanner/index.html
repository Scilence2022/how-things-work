行李安检机

机场安检机在几秒内「看穿」你的行李,靠的是一只会画线的眼睛:传送带把包拖进铅帘隧道,底部的 X 射线管发出扇形光束,正上方的探测器阵列逐线接收——包走一寸,图画一寸,像传真机一样把整个行李扫成一张数字影像。真正让安检员能「分物」的是双能技术:同一列探测器分高低两档管电压(或双层闪烁体)各收一遍,同一个像素就有了两份衰减数据——高能下光电吸收变弱而康普顿散射相对占优,元素越重、这个比例变化越陡;用两档数据的比值反推「等效原子序数」,就能给每个像素标上材质:有机物(水、塑料、炸药)橙红,混合物绿色,金属与无机物蓝色。再加形状识别:爆炸物与毒品有特征轮廓与密度,算法在图上叠出红色警报框,配合操作员放大、翻转、三视图切看。剂量账很克制:过一次安检机每件行李约 0.1-1 μGy,吃一根香蕉的天然辐射都比它多;真正被屏蔽的是操作员——射线源下方铅板与隧道铅帘把漏射线压到本底量级。与医用 CT 的差别在视角:安检机是单视角投影(叠加成像),CT 才是环形扫描三维重建,所以安检图上物物重叠是常态——操作员的本事就是把重叠的层次拆开。拖「传送速度」看逐线成像的节奏,拖「管电压」看穿透力与对比度;按「逐线成像」看扇形束画线,按「双能判物」看橙绿蓝上色,按「威胁报警」看算法叠框,按「铅帘防护」看射线被挡在隧道里。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
