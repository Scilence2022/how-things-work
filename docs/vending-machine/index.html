自动售货机

一台售货机要在三秒内回答三个问题:这是不是钱、是不是足够的钱、货掉下去没有。硬币从投币口滑入后先过「尺寸门」——直径与厚度任一超标当场分流到退币槽;再穿「材质关」:一组电磁传感器测涡流响应与电导率,真币的合金特征曲线对不上就判假币,钢芯镀层币在这一关现形;通过后按面值累加余额。余额够了,按键选中货道:电机的螺旋货道转过整圈,把最前排一件商品推出货架,商品坠入取货口时遮断一道红外光束——「出货确认」只有在光束被遮后才允许找零与结算,光束没断就是卡货,机器自动把钱退回或推下一位。整个闭环里最贵的是信任:日本售货机年流通硬币以千亿枚计,欺诈手段从棉线吊币到游戏币伪造,逼出了「光电确认+重量复核+退币口单向门」这套组合拳。演示里跟着一枚硬币走完鉴别全程,再看螺旋货道转一圈出货。拖「投币节奏」连续喂币,拖「货道圈数」看出货运动学;按「假币攻击」看钢芯币被弹回,按「卡货检测」看光束常通触发的退款,按「找零流程」看硬币雨。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
