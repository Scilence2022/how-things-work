闭门器 · 液压两段速关门

门要自己关上,又不能砰一声砸框——这件事被一只墙顶铁盒包办:齿条活塞液压机+主弹簧。开门时摇臂拧紧主弹簧储能(EN3 预紧 τ₀≈24 N·m,开到 90° 存进 ≈48 J),回油单向阀全开旁路,推门只需 25~40 N;松手弹簧推回活塞,单向阀落座,油液被逼着挤过可调节流阀——90°→15° 主速段走 3~7 s,15°→0° 锁速段换更细的节流孔,门贴上锁舌时只剩 ≈4 °/s,不撞锁不弹回。液压油的粘度随温度指数漂移(−20 °C 变稠 ≈14 倍,60 °C 稀到 1/5),温度补偿柱塞自动改开度,把关门时距钉回 ≈9 s——补偿失效,冬天门在半路停摆关不严,夏天两秒撞框;旁通阀片卡死则阻尼全失,门以 ≈144 °/s 砸框,锁舌迟早震松。拖「门开角/主速阀/锁速阀/油温」改工况,勾掉「温度补偿」看同温对照,按「关门全程/开门储能/旁通卡死/低温失灵」四幕演示,示波器实时画门开角与角速度的两段曲线。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
