凸包与单调链扫描:一根绳子绕出的最优边界

凸包是包含全部点的最小凸多边形——把钉子钉在平面上绷一根橡皮筋,绷直后的形状就是它。Andrew 单调链算法把「绕圈」变成「扫两遍」:先按 x 排序(O(n log n),也是全部复杂度的所在),再从左到右扫一遍建下链、从右到左建上链——每加入一个点,用叉积 (B−A)×(C−B) 检验栈顶的转向:右转(叉积 ≤0)就弹栈,直到左转才压入。上下两链首尾相接就是凸包,总复杂度 O(n log n),而且已证明这是下界——凸包不可能快过排序。共线点保不留、重复点怎么算,这些脏细节在叉积的 ≤ 与 < 之间一字千金。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
