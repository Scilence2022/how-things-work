落叶与离层

秋天树上掉叶子,不是枯死脱落,而是一台由激素计时、提前几周排期的「器官切除手术」。白天变短、温度下降,叶片先做回收:叶绿素被分解,氮和镁顺着叶脉撤回枝干存进过冬账户,被盖住的黄色类胡萝卜素这才显影,液泡里新合成的红色花青素再叠上一层红,秋天于是成了树叶的清算季。真正的开关是激素比值:只要叶片持续向叶柄「汇款」生长素,基部的离层就保持沉默;生长素流一旦断供,离层细胞对乙烯的敏感性暴涨,乙烯驱动细胞分泌果胶酶与纤维素酶,把中胶层和细胞壁一点点溶解,最后只剩几根维管束吊着;风一过,叶落,断口随即被栓化细胞封成一层防水防菌的「叶痕」。为什么必须落叶:常绿叶在冬天要面对蒸腾失水大于光合收益、枝冠积雪超载、气孔结冰三本亏账,一次性撤资比硬扛划算。同一套乙烯-生长素开关还管着果实脱落与花瓣凋零——采后「催熟」用的正是同一条通路。拖「季节进度」看叶绿素撤退与变色,拖「乙烯/生长素比」看离层提前启动;按「季节进程」看整枝换装,按「离层特写」看细胞壁溶解,按「激素开关」看生长素断供,按「常绿对比」看冬季两本账。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
