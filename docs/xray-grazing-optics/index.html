X 射线望远镜掠射光学

X 射线是出了名的穿透者,但这份穿透力恰恰让它无法用普通望远镜成像:光子近乎垂直地照到镜面时,既不反射也不折射,直接钻进玻璃或金属里被吞掉——1970 年代之前,天上所有的 X 射线「望远镜」都只是计数器,不知道光从哪来。解法是掠射:X 射线以小于临界角(几 keV 能段约 1°)的角度掠过镜面时,像石子打水漂一样被全外反射。沃尔特 1952 年的方案成为标准:先用抛物面把平行光收向焦点,再接一段双曲面二次反射,把轴上像差消掉——与卡塞格林光学望远镜同构,只是每个镜面都被拉成近乎平行的浅锥。单层镜面集光面积小,就把几十层抛光薄壳按同焦距嵌套:XMM-牛顿 58 层镀金壳堆出 4300 cm²,钱德拉 4 层壳把 0.5 角分的分辨率推到创纪录的 0.5″,能看清月球上的一枚硬币。代价是焦距被拉长到 10 m,钱德拉只能由航天飞机送入大偏心轨道——近地点 1.6 万公里、远地点 13.3 万公里,远超月球,让观测不受地球 X 射线辐射带污染,更不被遮挡。拖「光子能量」看临界角收窄,拖「掠射角」看反射率坍塌;按「垂直入射失败」看光子穿镜而过,按「沃尔特光路」跟随一次双镜反射,按「嵌套壳层」看集光面积堆叠。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
