生成对抗网络

2014 年,Goodfellow 把「让机器学会生成」写成一场博弈:生成器 G 吃进 100 维高斯噪声 z,吐出假样本 G(z);判别器 D 看一眼样本,吐出「这是真数据」的概率。两者共用一个价值函数 V(D,G)=E[log D(x)]+E[log(1−D(G(z)))]——D 拼命最大化它,把假货揪出来;G 拼命最小化它,让假货过关。理论上这场极小极大博弈存在纳什均衡:G 的分布与数据分布完全重合时,D 对任何输入都只能输出 1/2,「看不清」恰是「骗过了」的证明;训练因此像自由市场里造假者与鉴伪师的军备竞赛,双方轮流出招、交替升级。但两个网络同时学习并不安分,三道难题接踵而至:模式坍缩——G 发现只造一两种最安全的假货就能暂时骗过 D,输出多样性应声崩塌;不收敛与振荡——两股梯度互相干扰,损失曲线锯齿交锋、迟迟不肯落定;梯度消失——D 太强时 log(1−D(G(z))) 饱和,G 收不到误差信号,于是实操改用最大化 log D(G(z)) 的非饱和损失。修复工具箱随之成型:WGAN 用 Wasserstein(推土机)距离替代 JS 散度,让梯度在分布没对上的区域依然有效,再以权重裁剪或梯度惩罚维持 Lipschitz 约束;谱归一化压住 D 的火力,特征匹配与 mini-batch 判别专治千篇一律,条件 GAN 用标签给生成加上方向盘。2016–2020 年,GAN 是生成图像的主舞台:StyleGAN 逐级合成以假乱真的人脸,超分辨率、图像修复、数据增广全面开花,deepfake 则是同一枚硬币的阴影面;生成质量交给 Inception Score 与 FID 打分,FID 衡量真假两个分布的特征距离,越低越好。2020 年之后,训练更稳的扩散模型接管舞台,但对抗训练的思想并未退场——它活在对抗样本、生成对抗的评估博弈与 RLHF 的偏好对齐里。拖「学习率」看训练快慢与振荡,拖「噪声维度」看多样性与坍缩倾向;按「判别器攻势」「生成器反攻」「模式坍缩」「WGAN 修复」看四种战局。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
