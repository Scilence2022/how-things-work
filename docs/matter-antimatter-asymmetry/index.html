正反物质不对称

大爆炸应该造出等量的物质与反物质——粒子对撞机里,能量永远变出成对的粒子与反粒子。可今天的宇宙里,反物质几乎绝迹:每十亿个光子才配一个重子。如果早期宇宙严格对称,湮灭风暴之后应该什么都不剩,只有光子海——你不会存在。所以一定有什么在最初几分钟里,让物质多出了一丁点。萨哈罗夫 1967 年列出三个必要条件:重子数不守恒(有过程能改写「物质-反物质账本」)、C 与 CP 对称性破坏(物理规律对物质与镜像反物质不完全一视同仁)、脱离热平衡(反应来不及把不平衡抹平)。三者在标准模型里都存在,只是太弱:实验室测到的 CP 破坏(K 介子、B 介子振荡里,粒子与反粒子的衰变路径略有不同)足以让每十亿对里多留下一个重子——恰好是今天的比例。膨胀帮了大忙:宇宙降温太快,湮灭进行到一半时,「多余」的物质找不到反物质配对,湮灭冻结,剩下的物质存货(十亿分之一)留到今天,聚成恒星、行星与你。CP 破坏的微观机制仍在深挖:中微子振荡里的 CP 相角、强 CP 问题、电弱相变是否一级,都是粒子物理与宇宙学交界处最热的问题。拖「初始不对称」看存留物质的多少,拖「宇宙温度」看湮灭窗口;按「湮灭风暴」看正反粒子对闪灭,按「十亿分之一」看幸存者,按「CP 破坏」看介子振荡的偏心,按「冻出遗留」看湮灭如何冻结。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
