自定心卡盘

卡盘要回答一个刁钻的问题:三只卡爪怎么保证同时收到圆心?答案是藏在卡爪下面的「盘丝」:一块圆盘正面铣出阿基米德螺旋槽(平面螺纹),三只卡爪背面各镶一排与槽啮合的齿,互相错开 120° 插进同一条槽。扳手转动锥齿轮、带动盘丝旋转,螺旋半径随转角线性增大,于是三只爪在同一瞬间都沿各自径向槽滑动——同一条螺线、同一圈牙距,天生同心:夹毛坯棒料,跳动只有 0.05-0.15 mm,三爪自定心卡盘因此成了车床上用得最多的夹具。它的误差也来自这条螺线:牙距磨损不均、爪背与盘槽之间掉进铁屑、或盘丝分度有误差,跳动就被放大——精度要求高时改用四爪单动卡盘,每只爪独立调整,靠百分表找正到 0.01 mm;或者换软爪在自己机床上车一刀,让爪口长出与主轴完全同心的弧。夹紧力也是账本:扳手放大约 40 倍手力,但离心力随转速把卡爪往外甩,高速车削时夹紧力缩水,重切削必须算转速上限。拖「扳手转角」看三爪同步开合,拖「工件直径」看爪的行程;按「盘丝特写」看螺旋槽与爪齿的啮合,按「装夹误差」看铁屑如何制造跳动。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
