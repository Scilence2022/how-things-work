磁控管

微波炉的心脏是一枚手掌大的真空管,里面没有栅极没有偏转板,只有电场、磁场与一团会自己组织成轮辐的电子云——磁控管。结构像一朵铜花:中心是发射电子的阴极,四周环着偶数个谐振腔(每腔一个缝隙口),外加磁场沿轴向穿过。灯丝加热阴极,电子在径向电场的驱动下往外跑,却同时被轴向磁场用洛伦兹力掰弯:电场推它向外,磁场让它打转,两股力量的合力让电子只能绕着阴极做摆线运动——正交场(E⊥B)把直线运动锁成了旋转。旋转的电子云很快失稳成几条「轮辐」,像车轮辐条一样跟着场同步旋转;轮辐扫过谐振腔缝隙时,把能量交给腔里的电磁振荡,激起的频率由腔的尺寸决定——尺寸对准 2.45 GHz,效率高达 60-70%,一管输出千瓦级微波。π 模(相邻腔相位相反)是主力工作模式:恰好停在腔缝之间的电子处在减速场里,把动能如数上交;水分子吸收这个频段效率极高(偶极子跟不上每秒 49 亿次场翻转,热被直接写进食物),这也是频率被选中的原因之一。拖「阳极电压」看电子云与轮辐转速,拖「磁场强度」看摆线半径;按「电子轮辐」看旋转模式形成,按「谐振腔 π 模」看相邻腔反相振荡,按「微波输出」看天线把能量送进波导,按「整机耦合」看炉腔里的驻波与转盘。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
