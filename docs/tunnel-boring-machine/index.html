盾构机:一边啃岩、一边拼环,把隧道从土里顶出来

全断面隧道掘进机是一座行进的地下工厂:刀盘以 1-6 r/min、5-50 MN·m 扭矩旋转,17 英寸盘形滚刀每把以 250-350 kN 压碎岩石;16-30 组推进油缸撑在已拼好的管片环上,给出 2-6 万 kN 总推力,以 20-60 mm/min 掘进。土压平衡(EPB)靠双向调节:推进快则土仓压升、螺旋输送机转得快则压降,把仓压稳定在地层土压 0.1-0.3 MPa——掌子面不塌、地表不沉。每掘满一环(环宽 1.2-2.0 m)停机拼装:6-8 块管片由拼装机逐块成环、K 块封顶,同步注浆立即填满盾尾 5-10 cm 建筑空隙;纠偏靠分区油缸差压,最小转弯半径 250-500 m。地铁、高铁与引水隧洞的主力工法 · 3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
