停机问题与可计算性

1936 年,24 岁的图灵在论文里证明了计算机科学第一块基石,同时划下第一道天花板:不存在一个程序 H,能对任意程序 P 和输入 I 判定「P 跑 I 会不会停机」。证明只需五步:假设 H 存在;构造对抗程序 D——读入 P,去问 H「P 自己吃自己会不会停」,若答案是会,D 就当场死循环,若答案是不会,D 就立即停机;现在把 D 喂给 D:H 说 D(D) 会停 → D 陷入死循环;H 说不会停 → D 立即停机——两种情况都与 H 的判定矛盾,矛盾的唯一出口是 H 根本不存在。这个「自己反自己」的把戏与三年后哥德尔不完备定理同构:哥德尔构造「本命题不可证」的句子,图灵构造「本程序对自身判定取反」的程序,对角线法一脉相承。后果比想象中大:Rice 定理随后证明,任何关于程序行为的非平凡性质(「这个程序有没有漏洞」「这段代码是不是病毒」)都不可判定——不是难,是数学上不存在。工程上的退路不是放弃而是收窄:类型系统排除整类错误、有界模型检查只看 N 步内、测试与静态分析覆盖常见模式;而「这段代码会不会死循环」的日常疑问,永远只能对具体程序给出具体答案,没有通吃的银弹。拖「程序样本」切换被检对象,拖「步数上限」看模拟器卡死;按「悖论现场」看 D 吃 D 双灯齐灭,按「对角线网格」看与哥德尔的同款证明,按「Rice 定理」看性质判定的边界。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
