CFD 数值风洞

飞机还没造出来,工程师就先在计算机里把风「吹」了一遍——这就是 CFD 数值风洞。流体力学有三根支柱:理论是一组 Navier–Stokes 方程(动量方程:惯性 + 压力 + 黏性;连续性方程:散度为零),实验是风洞,数值模拟是第三条路:把连续流体切成上百万个小控制体(finite volume),对每个格子守恒记账——进出通量 + 源项 = 变化率,再用时间步一步步推进。压力和速度没有各自的现成方程,靠 SIMPLE/PISO 迭代拧到自洽;显式时间步还受 CFL 条件 Δt ≤ Δx/(u+c) 约束——格距越小、流速越快,步子必须越小,否则解直接发散。网格是 CFD 的地基:近壁边界层按 y+ 加密(气动计算通常要求 y+≈1),钝体后缘加密捕捉分离,网格的正交性与长细比决定解的可信度。最贵的是湍流:DNS 直接算所有涡,网格量按 Re^(9/4) 增长,雷诺数百万级的绕流要 10¹⁵ 量级格子——不可能;工程折中是 RANS(k-ε/k-ω 模型把脉动打包成涡黏性,一次稳态解、几百万网格)与 LES(直接算大涡、只建模小涡,成本高 10–100 倍)。粗网格还会「骗人」:它把涡街抹得对称、把阻力算低近两成——所以要用粗-中-细三套网格做收敛外推,再与风洞、飞行试验对表,升阻差常见 2–5% 才算过关。同一套数学,今天也在算飞机全机气动、汽车风阻与噪声、洁净室气流、血管血流和天气预报;一台翼型优化要跑上千个工况,云上算力替吹风分担了一半。最后别忘了「看图」:流线、涡量、Q 准则涡核、压力云图是 CFD 的一半——数据不画出来,等于没算。拖「来流速度」跨雷诺数 10³–10⁶,拖「网格密度」从 1 万格加到 300 万格;按「网格剖分」看网格生成与 y+ 加密带,按「粒子输运」看示踪粒子绕过钝体、尾流拉出卡门涡街,按「涡量涡街」看旋涡交替脱落的周期与斯特劳哈尔数,按「加密对比」看粗网格伪解与细网格真解并排对质。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
