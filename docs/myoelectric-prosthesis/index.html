肌电假肢:残端的肌肉还在发电

截肢后,残端肌肉只要还健康,收缩时照常发电:脊髓运动神经元放电激动肌纤维,动作电位经组织容积传导到皮肤表面,成为幅度 10 μV–1 mV、频率 20–500 Hz 的一片噪声毛刺——这就是表面肌电 EMG。信号链三步:表面差分电极(两片+参考)先抑制远方来的共模干扰;20–450 Hz 带通滤掉基线漂移与高频噪声,50/60 Hz 陷波对付工频;再整流取包络(RMS,时间常数 100–200 ms,太短抖动、太长迟钝),得到平滑的「用力程度」。最简单是双通道阈值控制:屈肌超阈值→闭合,伸肌超阈值→张开;比例控制把包络幅度映射成握力。进阶是模式识别:多电极通道提取时域特征(MAV、过零数、波形长度),分类器(LDA/小网络)识别四到八种手势意图,实验室准确率超过 95%。目标肌肉再神经支配 TMR 把截断的臂丛神经缝到残端其他肌肉上,把「手的信号」搬到皮肤表面——通道更丰富、手势库更大。最大短板是开环:手没有触觉,用户要靠眼睛盯;振动/电刺激触觉反馈闭环是前沿。日常挑战:电极移位、出汗衰减、肌电疲劳、电池一天一充。演示里拖动「收缩力度」看发光波沿肌束传播、原始肌电毛刺在示波器上抬起,包络过阈值后机械手开合;切「模式识别」看四条置信度条实时竞争;按「电极偏移」「出汗干扰」看误动作;勾选 TMR 看手势库翻倍。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
