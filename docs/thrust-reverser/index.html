反推力装置

一架 160 吨的客机以 280 km/h 触地,动能大到刹车盘会烧红,于是发动机在着陆后帮一把:反推装置把本来向后喷的风扇气流——大涵道比发动机约八成推力来自风扇——通过一圈可滑移的栅格门折向前方约 45°,产生 30–50% 的反向推力分量。主流设计是栅格式:涵道外壳向后滑移,露出导流格栅,气流从格栅折向前,湍流白雾扑过机翼;为什么只折「冷」的风扇流而不动滚烫的核心流:让 1000 °C 的燃气掉头,结构吃不消。反推还有三重账:缩短湿滑跑道的滑跑距离、给碳刹车降温省寿命(刹车是按热库设计的)、在积水/雪面上提供轮刹之外的稳定制动力;它的红线是「空中绝对不能开」——1991 年劳达航空 003 号班机在爬升中反推意外展开,飞机失速坠毁,此后所有反推都加了空地逻辑与多重机械锁;运行规矩也细:干跑道一般 idle 反推即可,噪声与磨损都最小,max reverse 只留给湿滑与紧急。拖「反推力度」看反向推力涨落,拖「跑道状态」看滑跑距离变化;按「展开动画」看栅格门滑出,按「气流折转」看粒子折向前方,按「着陆减速对比」看刹车温度计,按「空中锁定」看红线警示。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
