棘轮扳手

扳手头部里藏着一枚只有单侧齿面的齿环和两片被弹簧压住的摆动棘爪——人类给「反复拧紧」造的机械整流器。齿环与套筒、螺栓连成一体;爪子连在手柄壳体上,弹簧以 F₀ 把爪尖压进齿槽。正行程手柄顺时针压下,爪尖顶进齿背的陡直腰面:这一面近乎径向、还带负前角,拧的力越大,接触力越把爪子往齿槽里摁,扭矩一丝不漏地传到螺栓——T = F·L,100 N 手力 × 250 mm 力臂 = 25 N·m;双爪相位差半个齿距,任何时刻至少一只在线。回行程手柄反转,负载把齿环钉死,爪尖沿齿面爬坡:斜面角超过摩擦角(钢对钢 μ≈0.1 → 约 6°),爪子在斜面上压不住,被顶起、越过齿顶「咔嗒」一声落进下一个齿槽——手柄空跑,螺栓纹丝不动,每声咔嗒恰好 = 前进一个齿距。72 齿齿环的齿距只有 360°/72 = 5°:摆 5° 就能净进一格,这是棘轮扳手能在管道沟、机舱里 ±7.5° 净空下干活的原因;摆幅不足一个齿距,爪尖爬不完一个齿就被带回,螺栓分毫不动——空转。咬合上限由爪数×弹簧预紧决定:T_skip ≈ N·F₀·r/tanβ,双爪、F₀=60 N、爪尖半径 14 mm 时约 38 N·m(示意),手劲再大就「咔咔」跳齿打滑,扭矩传不出去;真扳手靠齿背负前角与更硬的弹簧把这条上限抬到上百牛·米。普通开口扳手没有这套机构:来回摆等于拧紧又松回,必须每 60° 抬起换一次手,受限空间里干脆卡死。拖「握力/摆幅/爪数/弹簧预紧」四个滑杆,按「正行程传扭/回程咔嗒/小摆幅空转/过载跳齿/普通扳手对照」看五种结局;表盘上蓝弧是当前摆幅,红括弧是一个齿距,蓝弧比红括弧短就注定空转。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停 - 场景要点: 桌台上立着一副剖视的棘轮扳手头:外圈是 72 齿的棘齿环(连着中央六角套筒与螺栓,背面顶进工件),外面套着半透明壳体环,壳体上伸出手柄与防滑握把;两片橙色摆爪从壳体铰点探进齿圈,尾部各挂一根压簧。正行程传扭模式里扭矩橙弧随手柄张开、螺栓跟着转、转角刻度累积;回程咔嗒模式里爪尖爬上齿顶、闪一声「咔嗒」、齿环纹丝不动;小摆幅空转模式把摆幅压到一个齿距以下,表盘蓝弧短于红括弧,扭矩弧消失、螺栓冻住;过载跳齿模式把手力拉过咬合上限,爪尖机关枪似的「咔咔」打滑;普通扳手对照模式收起双爪,手柄每摆 60° 就抬起来换手,±7.5° 净空里普通扳手卡死而棘轮照常一格一格前进。
