纺车与加捻:把一束毛变成一根线

纺车是一台用惯量换均匀的加捻机:脚踏大轮(飞轮)经弦带带动锭子,速比 6-15:1,锭速可达 1000-3000 rpm;大轮转得慢而沉,正是它的惯量把脚下忽快忽慢的蹬劲滤成稳定的锭速。纤维条子被手拉出,锭子每转一周就给纱加一个捻回,捻度 TPI = 锭速 ÷ 输出线速:捻回把只靠摩擦抱合的平行纤维压成螺旋包缠——纤维间压力随捻度上升,纱越捻越强;但过了峰值,过捻反而让应力集中、扭矩积蓄,纱会打卷断裂。捻系数 α = T·tex^0.5,棉纱常用 3.5-4.5。拉出速度一箭双雕:拉得快纱细、捻度也稀,拉得慢纱粗、捻度也密——均匀度全凭手上的稳定,这是纺纱的核心技能。S 捻/Z 捻方向相反,合股时反向互锁,纱才平衡不打卷。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
