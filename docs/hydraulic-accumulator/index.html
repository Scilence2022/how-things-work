液压蓄能器

液压系统最怕两件事:泵供油忽快忽慢,以及断电时执行器当场瘫痪。蓄能器是这台机器的「充电宝」:一只耐压钢瓶里装着充氮气的皮囊,油口在下——油不可压缩,气可以,于是氮气垫把泵送来的高压油存进瓶里,气体被压缩,压力沿气体定律爬升;等执行器需要大流量的一瞬(合模、刹车、举升),瓶口阀打开,氮气像弹簧一样把油瞬间推出去,一台小泵也能喂出一头猛兽的胃口。它还是系统的稳压器:柱塞泵每转都有流量脉动,蓄能器把波峰存起来补波谷,管路压力的锯齿被削平;泵突然停转或阀突然换向造成的水锤,也被这团可压缩的气垫当场吸收。断电保压是它最硬的用途:电网跳闸,泵停了,蓄能器独自撑住夹具的压力,模具不松、工件不掉;变电站的断路器操作机构、风机的变桨系统,都靠这瓶氮气在灾难时刻做最后一件事。设计账本只有一行:预充氮压通常取系统最低工作压力的 90%,工作压力与预充压之比决定它能吐出多少油——皮囊里存的是能量,账要按气体状态方程算。拖「预充压力」看可排油量的变化,拖「泵流量」看充压节奏;按「蓄能充压」看气体压缩,按「快速释放」看猛兽出笼,按「脉动吸收」看压力锯齿被削平,按「断电保压」看停电瞬间谁在撑住。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
