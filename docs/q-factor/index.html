品质因子与阻尼

敲响一支音叉,440 Hz 的余音能绕梁十几秒;把同样的能量交给汽车悬挂,半秒就归于沉寂——决定差别的只有一个数字:品质因子 Q。Q 有三种等价定义:2π×储能÷每周期耗散的能量、谐振峰的 f0/Δf(−3 dB 带宽)、共振时的振幅放大倍数,三者恒等;用阻尼比 ζ 写成一条公式就是 Q=1/(2ζ)。量级天差地别:汽车悬挂 Q<1,过阻尼才坐得稳;吉他弦数百,余韵是音乐的一部分;音叉数千,440 Hz 的标准音站得住;石英晶振 10⁴~10⁶——32768 Hz 的石英音叉凭高 Q 把频率锁得纹丝不动,1969 年精工 Astron 据此把日误差压进 0.5 s,机械表的统治就此落幕;微波谐振腔 10⁴,光学腔 10⁸,原子钟 10⁹。ζ 还决定回稳性格:ζ<1 欠阻尼,压下去弹几下才停;ζ=1 临界阻尼,不超调、最快回稳,门闭尼器与仪表指针都设计在它附近;ζ>1 过阻尼,反而慢吞吞。量 Q 也有懒办法:锤子敲一下,记下自由衰减曲线,相邻两峰之比取对数得 δ=2πζ/√(1−ζ²),轻阻尼下 Q≈π/δ——吉他弦与音叉的 Q 都是这么敲出来的。Q 还怕「漏水」:任何附加损耗都记在分母上——石英微天平镀一层纳米吸附膜,Q 立刻变矮,实验室靠这一变化称出单个分子层的质量;脱水机脱水时转速恰好扫过机身固有频率,整台机器咚咚撞墙,工程师只能在基座里垫阻尼胶。高 Q 的代价是窄:峰高≈Q,带宽=f0/Q,Q=10⁵ 的晶振带宽仅 0.33 Hz,只对 32768 Hz 附近的驱动响应;可频率一旦落进峰内,振幅放大 Q 倍——1831 年曼彻斯特布劳顿吊桥被齐步走的士兵踩塌,军队从此过桥改便步;2000 年伦敦千禧桥开放日人潮诱发侧向共振,摇摆如醉汉,加装 91 个阻尼器、闭门两年才重开。钟表与滤波器要高 Q 锁频,悬挂与减振要低 Q 吃振,传感器在中间折中——一个 Q,两种脾气。拖「阻尼比 ζ」看振铃变迟钝,拖「驱动频率(×f0)」扫过共振峰;按「自由振铃」看指数包络与对数衰减,按「扫频共振」看洛伦兹峰长出来,按「临界阻尼」看不超调的一步回稳,按「能量耗散」看每周期 2πE/Q 的热流。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
