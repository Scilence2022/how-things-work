电石灯

电灯普及之前,矿工和洞穴探险者的头灯烧的是一块「石头」:电石——电弧炉里用 2200 °C 把石灰和焦炭强行撮合出的碳化钙,遇水就拆伙:CaC₂+2H₂O→C₂H₂↑+Ca(OH)₂,放出的乙炔从喷嘴冒出,点燃即得一盏亮灯;电石灯的构造是一台滴水定时器:上仓装水,旋钮控制滴阀,水一滴一滴渗进下仓的电石——滴速就是亮度旋钮,滴得快火苗窜高、电石也烧得快;乙炔含碳量高,火焰里满是炽热的碳粒,亮度远超煤油灯且几乎无烟,又是全谱暖光、不像 LED 发蓝,照得清岩壁层次——矿工靠它照了一百年巷道,洞穴探险家靠它画了几十年地图;它也有脾气:乙炔压强超过约 2 个大气压会自分解爆炸,遇铜银还会生成敏感的乙炔铜,所以灯体只靠水封低压供气、气路绝不用铜;最危险的是熄火误操作:水汽把火吹灭而气还在冒,乙炔积聚越过爆炸下限,遇明火就轰燃——所以熄火要先关阀通风,清理熟石灰糊前先冲净残存电石;今天钢板切割车间里约 3100 °C 的氧炔焰,正是这盏矿灯化学反应的高温后代。拖「滴水速率」看火苗涨落,拖「电石余量」看反应家底;按「反应供气」看滴水产气链,按「亮度调节」看火焰随滴速起伏,按「洞穴探险」看光锥扫过钟乳石,按「误操作风险」看熄火积气的轰燃前夜。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
