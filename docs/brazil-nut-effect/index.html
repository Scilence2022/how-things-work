巴西坚果效应

摇一罐混合坚果,最大的巴西坚果总会浮到顶上——可颗粒世界里没有浮力:颗粒床是力链撑住的「固体」,压强分布偏离静水压,阿基米德在这里当场失效。上浮其实靠三台机器。其一,振动让床活过来:无量纲加速度 Γ=a·ω²/g 大于 1,床面才开始流化,并卷出一对「对流环」——中央颗粒缓缓上升、沿罐壁下滑,大颗粒被这条传送带送到顶部,却因个头太大,钻不进沿壁下滑的窄流,上去就回不来。其二,「空隙填充」:每次振动把床面抬起,大颗粒下方张开的空隙,几乎总被随机钻动的小颗粒抢先填占——大颗粒一步一个脚印,只进不退。其三,大颗粒底部更容易成拱,留下的空隙更大,被填得也更快。参数走到极端剧情会反转:频率高到床面局部流化,或两种颗粒密度差反号,大颗粒反而随流化床下沉——这就是反转巴西坚果效应。工程上它一半是灾难一半是工具:药片混料越摇越不均,滑坡体自动把巨石分选到表面,隼鸟二号的着陆实验还在小行星表面拍到砾石随振动迁移的现场证词。拖「振动频率」调床的活性,拖「振幅」看每次抬起的空隙;按「对流抬升」看传送带卷大球,按「空隙填充特写」看小球钻缝,按「反转效应」看大球掉头下沉,按「工程案例」看药片越摇越不均。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
