胎儿血液循环

胎儿的肺是不工作的,替班的是胎盘,所以胎儿心脏最大的工程不是泵血,而是把血绕开肺送出去:脐静脉从胎盘带回氧饱和度约 80% 的血,一进右心房就走捷径——静脉导管让它绕开肝脏直下下腔静脉;卵圆孔让右心房的血直接漏进左心房,优先供给脑和心;动脉导管把本该进肺的右心室血改道进降主动脉,真正进肺的血只占心输出量约 10%。抢氧靠胎儿血红蛋白 HbF:氧解离曲线比成人左移,P50 约 19 mmHg(成人约 27),同样氧分压下硬把氧从母体血红蛋白手里夺过来。出生是血流改道的硬切换:第一口气撑开肺泡,肺血管阻力骤降,肺血流从一成暴涨到接下全部右心输出;血氧飙升让动脉导管平滑肌收缩,24–48 小时内功能闭合;左心房压力反超,把卵圆孔瓣膜像门一样压贴。改道失败就是先天性心脏病:动脉导管未闭(PDA)让主动脉血持续漏进肺动脉,青紫与心衰随之而来——早产儿用布洛芬抑制前列腺素促闭,大龄患儿塞封堵器。拖「肺血管阻力」看肺血流占比怎么随阻力塌缩与暴涨,拖「动脉血氧饱和度」看血色深浅与曲线标记;按「胎儿循环」看三条捷径的默认走线,按「出生切换」看三条捷径依次闪红闭合,按「PDA 病理」看导管持续漏流,按「HbF 氧解离」看两条 S 曲线对比。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
