烯烃复分解

两条烯烃跳了一场交换舞伴的舞:C=C 双键的两半互相换了对象——A=B + C=D 变成 A=C + B=D,碳原子重新配对而总价电子数不变,这场舞叫烯烃复分解。化学家困惑了二十年:双键那么强,凭什么说换就换?夏尔万 1971 年给出答案:催化剂不是把双键拆开,而是自带一条「金属=碳」双键(金属卡宾),先与烯烃发生 [2+2] 环加成,生成一个四元环(金属环丁烷)中间体;四元环再裂开时,裂的位置换了——金属卡宾带着一半烯烃走了,把另一半留给剩下的碎片,一轮交换就此完成,催化剂复原,进入下一轮。格拉布把催化剂换成钌卡宾:空气里稳定、容忍水与醇,1990 年代起这场舞走进天然产物全合成与药物工厂;施罗克则用钼,活性更高但娇气——2005 年诺贝尔化学奖授予这三人。复分解还有一件绝活:关环复分解——一条链两端各带一个烯烃,分子内换伴,链子首尾相接成环,五、六、七元环信手拈来;石化厂里则用自复分解把丙烯变成乙烯与 2-丁烯,让碳骨架按市场需求搬家。拖「反应进度」看一轮交换的来龙去脉,拖「催化剂负载」看周转数;按「换伴一轮」看四元环的开与合,按「关环复分解」看链子咬尾成环,按「自复分解」看丙烯的重新分配。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
