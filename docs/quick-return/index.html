牛头刨床与急回特性

曲柄匀速旋转,滑块在摆动导杆槽里滑移,把等速转动变成往复摆动→工作行程扫过远弧 180°+θ,慢而近似匀速,适合切削;回程走近弧 180°−θ,抬刀飞退→行程速比 K=(180°+θ)/(180°−θ),θ=2·arcsin(r/e) 只由曲柄与机架的几何决定:偏距比 r/e 越大,急回越猛→省下的全是非切削时间 · 拖动旋转 / 空格运行/暂停
