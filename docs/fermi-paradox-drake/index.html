费米悖论与德雷克方程:他们都在哪儿

银河系里有约 4000 亿颗恒星、130 亿年历史,为什么我们一个外星人都没见过?1961 年德雷克把「可交流文明数」拆成七项连乘:N=R*·fp·ne·fl·fi·fc·L——恒星形成率 R*≈1.5-3 颗/年,开普勒与 TESS 证实行星比恒星还多(fp≈1),每套行星系统的宜居行星 ne≈0.1-0.4:前三项望远镜已经给出量级;生命出现 fl、演化出智慧 fi、发展出可探测技术 fc、技术文明寿命 L,全靠地球这一个样本外推,谁也不敢签名。把偏乐观的数字代进去,N 轻松上几十上百;而就算只有 0.1c 的慢船、每跳休整 400 年,扩散前沿铺满银河也只要约 100-1000 万年——只是银河 130 亿岁的千分之一。于是费米 1950 年在午餐上问:「他们都在哪儿?」主流答案是大过滤器:生命起源(有机→自复制极难)、真核与复杂生命(地球拖了 20-30 亿年)、智慧、技术、或自我毁灭(核战/生态/AI),这一刀要么砍在我们身后(我们极其稀有,前方坦途),要么砍在前方(大难临头);别的回应还有动物园假说、黑暗森林、我们太早(宇宙大部分寿命还属于红矮星时代),以及无线电窗口天然很短——地球的全向广播只持续了约 100 年就转向光纤与定向链路,L 可能本来就小。SETI 搜的是技术签名(窄带信号、巨工程凌星),1960 年至今唯一候选是 1977 年那 72 秒的 Wow! 信号,再未复现。演示里拖动七个方程滑块,看 N 与银河中亮起的文明点联动(对数条形实时变化);点「殖民扩散」选一个文明发射波纹,看计时条与银河年龄对比;点「大过滤器」切换这一刀砍在哪一环;点「时间轴」把 138 亿年与 100 年摆在一起。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
