动力转向:扭杆探意、阀门放大

方向盘转动的是一根扭杆,而不是车轮:扭杆上端接转向柱、下端接小齿轮,刚度约 1-3 N·m/°,驾驶员用 2-6 N·m 的力就能把它拧转 2-8°——这个微小转角就是「意图信号」。转阀的阀芯与阀套随之一开一合,把高压油导进齿条活塞一侧:叶片泵由发动机皮带驱动,流量 6-12 L/min、压力最高 10-14 MPa,压差给齿条 5-12 kN 的助力,轻轻一盘就到头(锁到锁 2.5-3.5 圈)。不打车时阀居中,油在泵-阀-油壶之间空循环,泵照转,白白吃掉 0.5-1 kW。EPS 干脆删掉液压:扭矩传感器读意图,ECU 按车速 MAP 给电机助力——低速轻快、高速沉稳,省油 0.1-0.3 L/100 km,还能做主动回正。助力一旦失效,法规要求纯人力也能转向:25-40 N·m 的方向盘扭矩,慢,但转得动。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
