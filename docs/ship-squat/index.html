浅水效应:船体下沉与岸吸

浅水会改变一切:船向前走,必须把同体积的水往后送,河床就在船底几米处,过流断面被船身卡掉一大半——水只能加速钻过船底,压强随之下降(连续性+伯努利),船体被整体往水面下按,这就是船体下沉 squat,而且船尾比船头沉得多,形成尾倾。经验式 δ≈Cb·V²/100(米,V 用节,方型系数 Cb≈0.8):12 节在开敞浅水约沉 1.15 m,进运河这类受限水域还要再乘 ~2;水深吃水比小于 1.2 时最危险。它随速度平方增长:速度加倍、下沉四倍——港区限速 8-12 节不是噪音规定,是龙骨保命线。贴近岸壁或与邻船并行时,内侧水道更窄、流速更快、压强更低,船会被『吸』过去,1911 年 Olympic 就这样被巡洋舰 Hawke 撞出大洞,法院判定元凶正是船吸。拖动「航速」滑杆看船身当场下沉、龙骨下剩余水深(UKC)读数闪红;拖「水深/吃水」与「岸距」看流线由绿转红。按「两船并行」复现互吸场面。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
