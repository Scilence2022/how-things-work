风浪的诞生:从一厘米的涟漪到大洋的涌浪

绝对平静的水面上,风怎么造出第一道波?先靠 Phillips 共振:大气湍流的压强起伏含有各种波长成分,与水面微扰共振的分量把能量线性注入——最先长出波长 ~1.7 cm 的毛细波,那里表面张力当恢复力,相速度正处 23 cm/s 的谷底。毛细波一出现,镜面作废,Miles 切流不稳定接管:波峰上方的临界层把风的动量按周期泵进与波速同频的分量,波幅以指数生长。波长越滚越长,恢复力从表面张力换岗给重力,波龄 c/U₁₀ 从 0.2 的尖陡幼波长到 1 的圆润老波;显著波高沿风区按 F^0.5 走 JONSWAP 包络,充分发展海况由 U₁₀ 封顶。陡度 H/L≈1/7 是破碎上限,一过就卷出白帽;风停之后,老波跑出风区成为涌浪——色散把长波排到最前面,冲浪者等的就是这份比风更老的余生。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
