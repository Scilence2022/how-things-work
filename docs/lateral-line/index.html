鱼类侧线

鱼身上装着一排「会漏水的水听器」:从鳃盖后缘沿体侧一直排到尾柄,再爬上头部绕着眼眶与颌转一圈,加起来上百个神经丘(示意 ~200 个)。每个神经丘是一小片埋在表皮凹坑里的毛细胞上皮,顶上罩着一顶凝胶浇成的钟形顶器(cupula)——密度几乎与水一样,水怎么动它就怎么动,一点不隔。水流把顶器偏斜零点几微米,埋在基底的毛细胞束就被牵动:阶梯排列的静纤毛顶着最高的动纤毛,朝动纤毛一侧偏转时,顶端连接拉开的机械转导通道放 K⁺、Ca²⁺ 涌入,毛细胞去极化、突触持续释放谷氨酸,侧线神经纤维上的放电率当场改写——整条换能链潜伏期不到 1 ms,通道开启只需要毛束位移约 10 nm(示意),是已知最快的机械-电换能,与内耳毛细胞用的是同一张图纸。神经丘分两档:皮表神经丘直接泡在水里,调谐 ~10~50 Hz,盯环境暗流;皮下神经丘坐在充满液体的小管里,管壁小孔放大局部压力梯度,对 ~50~200 Hz 敏感,专追猎物摆尾甩出的涡迹。相邻神经丘的毛细胞极性常常相反:同一股水,一群放电升、另一群降,流向由此读出;整排阵列再比较各点响应的先后与幅度,涡迹的方位、距离、大小全可反演。这三样本事写进鱼的日常:黑暗里凭涡迹锁定猎物(盲鱼、斗鱼夜间全靠它),结群游动时读邻居尾流保持间距不追尾(盲洞鱼没有眼睛也能整群转向),入水口或暗流一变就调姿稳住。失效也干脆:链霉素、庆大霉素这类氨基糖苷抗生素对毛细胞有选择性毒性,侧线与内耳一起遭殃;机械损伤则直接掀掉顶器——涡迹还在,鱼却成了盲猎,而视觉嗅觉完好,恰好是最干净的对照实验。拖「环境流速」看暗流让全阵列同向偏斜,拖「涡迹频率」扫 10~200 Hz 调谐带,拖「顶器刚度」挪共振峰,拖「猎物距离」看涡迹衰减;按「涡迹追踪 / 神经丘特写 / 集群避碰 / 暗流感知」切换场景,按「侧线失效」看转导归零后的盲猎。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
