瞬干胶:你手指上的潮气就是引发剂

氰基丙烯酸酯单体 CH₂=C(CN)COOR:碳碳双键两侧顶着氰基与酯基两个强吸电子基,电子云被两头抽走,β 碳带明显正电性——亲核试剂眼中的「破门」。被粘物表面潮气(40-60% RH 下 nm 级水膜)里的微量 OH⁻ 就是引发剂:攻击 β 碳 → 双键电子重排 → 碳负离子 → 阴离子连锁加成,每步毫秒级,1 秒内聚合度冲到 10³-10⁴ 并放热——所以它「瞬干」。单体粘度刻意做到 2-5 mPa·s(近水),先润湿、再毛细钻进微观粗糙度,固化后微销钉给出 10-20 MPa 剪切强度。皮肤上有水还有氨基酸碱基,引发剂管够 → 秒粘;聚乙烯无极性、~31 mN/m,不润湿也不供引发位点 → 不粘。弱点:高度交联的玻璃态网络硬而脆、耐热 ~80 °C、挥发单体再聚合造成「白化」;RH>80% 水太多提前自聚、过干引发不足都掉强度;增韧版掺橡胶微球,丙酮/热碱可解聚。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
