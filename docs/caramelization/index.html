焦糖化:一勺糖的温度阶梯

焦糖化是纯糖在无氨基条件下的热分解——美拉德反应 ≥140 °C 起且必须还原糖+氨基酸,二者常被混为一谈。温度是唯一的旋钮:果糖 110 °C 起、蔗糖 170 °C 起;路径为糖苷键断裂→葡萄糖/果糖烯醇化异构→脱水生成 HMF、麦芽酚、二乙酰(黄油香)、呋喃→缩合聚合为焦糖素(caramelans/caramelen):共轭链变长,吸收带进入可见光,颜色由金黄转向深褐。糖果阶段表全靠温度定型:拉丝 110-112、软球 112-116、实球 118-120、硬球 121-130、软裂 132-143、硬裂 149-154 °C——含水率随沸腾一路走低,硬度就是温度的存档。加柠檬酸催化蔗糖转化(果糖+葡萄糖)可防返砂;过了头就是碳化。糖艺就是一台温度计。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
