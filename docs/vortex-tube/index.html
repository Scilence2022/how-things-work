涡流管

一根没有活动部件的管子,接上压缩空气,一端出热风(可达 100 °C 以上)、一端出冷风(可低到 -40 °C)——涡流管(Ranque-Hilsch 管)是热力学里最像魔术的装置:压缩空气切向喷进管子,以每分钟百万转量级的速度贴壁旋转着冲向热端;中心部分的气流被迫反向,从中央小孔流出——就是这股中心流变冷了。能量是怎么分开的?解释至今仍在打笔墨官司,主流图像是:贴壁高速旋转的外层气流与内层强烈剪切,把能量重新分配;外层气流的切向速度沿管衰减时经历绝热膨胀与「声流」效应——结果是外层更热、内芯更冷,同一根管子内温差可达 50-70 °C。它效率不高(等熵效率只有百分之几到十几),但胜在零活动部件、即开即用、工质只有空气没有制冷剂:点焊枪头局部冷却、高温车间的岗位送冷风、气体分析仪的取样降温、矿井里的便携冷源,都是它的岗位。热端那枚小阀是唯一的调节钮:拧进拧出改变热流背压,从而分配冷热流比例(冷流分数 20%-80%),温差与冷量在滑杆两端此消彼长。拖「进气压力」看旋涡转速与温差,拖「热端阀开度」看冷热分配;按「冷热分流」看两股流分道,按「温度剖面」看管内径向温度分布,按「调节冷流比」看阀如何再分配,按「与冰箱对比」看效率的差距。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
