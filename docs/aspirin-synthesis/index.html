阿司匹林

头痛、发热、防血栓,人类吃得最多的药片之一诞生于柳树:几千年前人们就嚼柳树皮止痛退热,1828 年从中提取出水杨苷,1838 年制得水杨酸——退热镇痛消炎样样在行,却苦涩伤胃,不少病人因胃痛被迫停药;1897 年拜耳的费利克斯·霍夫曼给水杨酸的酚羟基「戴上乙酰帽」,用乙酸酐一步酯化得到乙酰水杨酸,刺激大减而药效保留,1899 年以 aspirin 之名上市——A 是 acetyl(乙酰),spir 取自绣线菊 spirea,in 是药名后缀;合成本身干净利落:水杨酸 C₇H₆O₃(摩尔质量 138)加乙酸酐(102),浓硫酸催化,水浴 80–85 °C 约 15 分钟,产出乙酰水杨酸(180)与乙酸(60),冷水洗去乙酸,乙醇-水重结晶,熔点 135 °C 是纯度的答卷;它也会倒着走:酯键遇潮气缓慢水解回水杨酸与乙酸,老药片的醋味正是警告,升温与碱性更会加速变质,所以要肠溶衣加干燥保存;进入人体,阿司匹林把环氧酶 COX 活性位点的 Ser530 共价乙酰化,通道锁死、前列腺素断供,痛、热、炎三路减轻;血小板血栓素 TXA₂ 同样断供,于是小剂量 75–100 mg/日长期防血栓——血小板没有细胞核,被不可逆抑制后只能走完 7–10 天的一生;而 300–500 mg 的一片,则是镇痛退热的常规剂量。拖「反应温度」看产率涨落,拖「环境湿度」看水解快慢;按「合成反应」看乙酰基挂上酚羟基,按「重结晶提纯」看晶体生长、杂质沉底,按「水解变质」看酯键断裂、醋雾升腾,按「体内药效」看 Ser530 锁死通道。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
