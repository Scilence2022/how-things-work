电渗析脱盐

把一摞只让阳离子或阴离子穿过的塑料膜交替叠起来,两端通上直流电,盐水就在膜与膜的夹缝里自己分成淡水与浓水——这就是电渗析:阴离子交换膜只放阴离子,阳离子交换膜只放阳离子,电场当搬运工。钠离子向负极跑,穿过一张阳膜进入隔室,却迎面撞上阴膜过不去,只好留下;氯离子向正极跑,穿过阴膜又被阳膜拦住——于是每隔一室,离子只出不进,成了淡水室;相邻的室只进不出,成了浓水室。与反渗透靠压力挤水过膜不同,电渗析搬运的是盐不是水,所以特别适合中低盐度水(苦咸水、高硬度地下水):盐度越低越省电,能耗大致随脱盐量线性走;而海水淡化仍是反渗透的主场。它的软肋是浓差极化:电流过大时,膜面的离子来不及由主体水补充,水分子被电解析出氢与氢氧根,碱性边界层让钙镁在膜面结垢,脱盐率掉头向下;对策是控制在极限电流以内运行,或者定时倒极(EDR)——让电场每几十分钟反一次向,刚析出的垢被新环境溶解,膜堆自清洁。离子膜还不挑对象:乳清脱盐、氨基酸分离、废水酸碱回收,同一套膜堆换个进料就是另一条产线。拖「工作电压」看离子迁移与脱盐率,拖「进水盐度」看能耗账本;按「脱盐运行」看淡浓分道,按「浓差极化」看结垢如何发生,按「倒极清洗」看垢被反向溶解。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
