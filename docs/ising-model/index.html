伊辛模型:小磁针如何集体转向

一块铁为什么自己有磁性?伊辛模型给出最简答案:格点上每个自旋只取 ±1,能量 E=−J·Σ⟨ij⟩ sᵢsⱼ−h·Σsᵢ——求和只对相邻格点,J>0 时同向能量低(铁磁)。温度与相互作用在拔河:kT 大,熵赢,自旋乱指,净磁化为零(顺磁相);kT 小,能量赢,自旋抱团成畴再吞并成整块,自发磁化出现(铁磁相)。二维正方格子有精确解(Onsager,1944):临界温度 Tc=2J/(k·ln(1+√2))≈2.269 J/k,此处磁化率与比热发散、关联长度无穷大——二级相变;团簇什么尺度都有、边界分形。模拟用 Metropolis 蒙特卡洛:随机挑一枚自旋算翻转代价 ΔE,ΔE≤0 直接受,否则按 exp(−ΔE/kT) 的概率受——温度越高越敢犯错。淬火(急冷)把高温的混乱冻成红蓝相间的磁畴花斑;退火(慢冷)则聚成大块单畴。外场 h 拉偏天平,低于 Tc 来回扫外场还能看到磁滞——硬磁材料「记忆」的来源。同一套数学还描述格气、合金有序化、Hopfield 神经网络——相变的普适性:细节不重要,只看对称性与维度。演示:24×24=576 枚双色小立方实时演化(平面格子:精确解仅在二维成立),温度/外场/J 滑块即拖即变,散点图累积 (T,|M|) 并与 Onsager 竖线对比;试「淬火」「退火」「外场翻转」三连。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
