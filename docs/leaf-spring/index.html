钢板弹簧

几条弧形钢板摞在一起,就是一台既承重又减振的「叠叠乐」:主片两端卷成卷耳用销轴连到车架,其余各片渐次缩短,中央用中心螺栓夹成一体,骑马螺栓把它捆在车桥上。车轮跳起来,力从卷耳传进来,整叠钢板被压扁——弧高减小、刚度上升,把冲击存成弹性势能;而真正的魔法在片与片之间:钢板受弯时各层要滑移,干燥钢面对钢面的摩擦把一大部分振动能量当场磨成热量,弹簧自己就是自己的减振器——老卡车过坎后「咯吱」作响,正是片间摩擦在干活。片数还是天然的变刚度开关:空载时只有主片与次片受力,刚度小、颠簸轻;满载重压下更多短片参加进弯矩分配,刚度与承载一起涨——一条弹簧同时伺候空车与满载。代价是片间摩擦可能卡滞:小颠簸被摩擦锁住直接传进车身,所以现代轿车改用螺旋弹簧加油压减振器,钢板弹簧留在了货车与硬派越野车上——结构简单、能吃重、坏了换一片就能走。拖「载荷」看弧高与刚度变化,拖「板片数」看谁参加受力;按「过坎冲击」看能量进出的账本,按「卷耳特写」看端部怎么留出滑移空间,按「片间摩擦」看振动被磨成热量。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
