内窥镜:一根能拐弯的眼睛

不用开刀就能看见胃里的一小块溃疡——内窥镜把「眼睛 + 手电 + 机械手」全部塞进一根 9 mm 的软管。头端四件套:物镜(视场 140-170°)、导光束(体外冷光源把强光送进来,体内只留冷光不灼伤)、水气通道(冲洗视野、充气撑开腔体)、器械通道(2.8-3.7 mm,活检钳、圈套器、注射针都从这里进)。弯曲部是灵魂:四根钢丝两两一组,L/R 与 U/D 两个手轮拉这头、松那头,几厘米长的弯曲段就能拐出 210° 以上、弯曲半径 5-10 mm——在幽门皱襞之间掉头。图像走两条路:老一代纤维镜用「传像束」——上万根光纤按完全相同的排列熔在两端,每根光纤靠全反射传一个像素,断一根就永远死一个点;现代电子镜干脆把 CMOS/CCD 塞进头端,体内拍照、导线传电,分辨率到十万~百万像素,NBI 窄带成像还能突出黏膜血管纹理。胶囊内镜是它的极简版:26×11 mm、LED + 相机 + 电池,每秒 2-6 帧,靠蠕动自然推进 8-14 小时拍完小肠。数字:胃镜外径 9-10 mm,插入深度 ~1 m,可做活检、息肉切除、止血夹、支架——看到即治到。演示里拖「插入深度」沿食道进胃,拖 L/R 与 U/D 操纵弯曲部,监视器画面(左下示波窗)实时变化;对准红色病灶按「活检钳」取样;切「纤维镜」看传像束剖面与断丝死点;按「胶囊内镜」看它随蠕动漂完小肠。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
