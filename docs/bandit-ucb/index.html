多臂老虎机与UCB

一排三台老虎机,中奖率 0.42 / 0.30 / 0.55(示意)且对你保密:每次拉杆既是在「吃」当前看起来最好的老臂,也是在给冷门的新臂采样——只利用会被次优臂套牢,只探索又把赢面全交了学费。策略优劣折成一个数:累计遗憾 R_n = n·μ* − Σ μ(aₜ),即与全知策略的收入差。UCB1(Auer 等,2002)给拉得少的臂加置信奖金 c·√(2 ln t / n):奖金随样本数按 1/√n 塌缩,「不确定」本身变成吸引力,冷门臂自动轮到机会;定理保证遗憾 ≤ ΣΔ + 8 ln n·Σ1/Δ = O(log n),而 Lai–Robbins(1985)证明 ln n 是任何策略都躲不开的地板。对照:ε-greedy 每 1/ε 次就白扔一次、遗憾按线性爬;ε=0 的纯贪心开局手气定终身,n=10⁴ 时白丢上千枚;Thompson 采样(1933)用 Beta 后验抽签,天生平衡。同一套数学撑着 A/B 测试与广告投放:5%→6% 的转化提升按固定分流要 ≈0.8 万样本/臂才能裁决(p<0.05),bandit 把流量实时滚向赢家、少给输家送转化。拖「探索系数 c / ε / 拉杆速度」改策略,按「UCB1 / ε-greedy / 贪心失效 / 纯随机 / Thompson」五策对照,示波器会留下各策略的遗憾曲线:蓝的弯、红的直,高下立判。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
