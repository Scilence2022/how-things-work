磁制冷与磁热效应:让磁场当压缩机

磁制冷不压缩气体,它打熵这张牌:给磁热材料加磁场,自旋磁矩集体顺场排列、磁熵骤降——绝热条件下总熵不能凭空消失,晶格熵只好补位,材料自己升温;撤掉磁场,自旋重新乱化、从周围吸热,材料又凉回去。可惜单级温升只有几 K:金属钆的居里温度恰在室温附近(约 293 K),1 T 磁场绝热温升约 2.5-3 K。家用靠 AMR 主动磁回热循环放大:磁化(向回热器放热)→ 热端换热 → 退磁(从回热器吸热)→ 冷端换热,工质带在冷热两端之间往返,回热器像梯子一样把小温升逐级叠成 20-30 K 跨度,循环频率 0.5-4 Hz。磁场源用 Halbach 永磁阵列(1-1.5 T),旋转内筒即可切换工位强弱场——不用超导、不用压缩机、不用 HFC 制冷剂,安静且效率可达卡诺 30-60%;工质按温区选:Gd₅Si₂Ge₂ 巨磁热、La(Fe,Si)₁₃、锰基合金。2016 年起饮料冷却器已有商用试点,家用冰箱在试。演示里看工质链节进强场区自旋排齐、发红放热,退出后乱化发蓝吸热;拖磁场强度(0.5-1.5 T)、循环频率(0.5-4 Hz)与冷端负载,看冷/热端温度曲线爬向稳态;点「Halbach 旋转透视」「自旋慢放」「T-S 循环图」分别看三门道。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
