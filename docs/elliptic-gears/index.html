椭圆齿轮:会呼吸的传动比

圆齿轮的节圆半径处处相等,所以传动比恒定;把节曲线换成椭圆,传动比立刻开始「呼吸」。两枚全等椭圆各绕一个焦点安装、中心距 2a:接触点永远落在连心线上,瞬时传动比 i = r₂/r₁;椭圆的极径 r(θ) = a(1−e²)/(1+e·cosθ) 在 a(1−e) 与 a(1+e) 之间周期变化,速比于是每转摆动一次,在 (1+e)/(1−e) 与 (1−e)/(1+e) 之间来回——e = 0.4 时是 2.33 与 0.43,输出轴快慢肉眼可见。包装机与印刷机正是用这段慢-快-慢:慢段完成裁切与停帧,快段拉开料距。反过来用就是椭圆齿轮流量计:两枚卵形轮每月牙腔排过固定体积,转数直接累加成总量,精度 ±0.2-0.5%,且与粘度基本无关,油品与化工计量仍在用。这一切都服从同一条啮合基本定律——接触点公法线过节点,只是节点不再固定,而沿中心线滑动。拖「偏心率 e」滑杆从 0.02 到 0.6,看速比指针摆幅与输送带上包裹的快慢节拍;按「定容计量」看月牙腔充排与累计流量;按「圆齿轮对照」回到 e≈0 的恒速世界。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
