化油器

化油器是一台用空气自己给自己称油的机器:活塞下行吸气,空气涌入喉管;喉管把通道直径缩到约一半,按连续性原理流速立刻升到约 4 倍,而伯努利方程 Δp=½ρ(v₂²−v₁²) 甩出的账单是——流速暴涨处静压大跌,巡航时喉口真空可达 5–20 kPa。浮子室经通气孔保持大气压,汽油就被这股压差沿主量孔压上喉口,被上百公里时速的气流撕碎成雾,混成可燃混合气进缸。天才之处在账目自洽:量孔油量 ∝ √Δp ∝ 流速,空气量也 ∝ 流速,分子分母同涨同跌,混合比自动锁在汽油理论空燃比 14.7:1 附近,全程无需油泵与传感器。但它有个软肋:低速气流慢,喉管压差小到吸不上油,于是怠速量孔、过渡孔、加浓阀(功率量孔)、加速泵组成一套「小孔网络」接力;浮子+针阀用马桶水箱原理把油面钉在喷口下方一两毫米,保证吸油压差只看喉管真空、不看剩油多少。冷启动靠「以浓补挥」:低温汽油饱和蒸气压低、不肯挥发,关小阻风门让真空暴涨、吸出过量的油,空燃比掉到 3–5:1,富油易点,排气管先喷几秒黑烟,暖机后阻风打开,回到约 14.7:1。高原上空气密度从 1.225 kg/m³ 跌到约 0.82(4000 m),油却照旧,混合气过稀到 18+:1,动力下降甚至回火,得换小号主量孔。最终判它出局的是环保:三元催化器要求 λ 锁死在 1±0.5% 的窄窗,开环做不到——1980 年代起氧传感器闭环+电磁喷油器的电喷接管汽车;但凭零电子件、一桶油就能修好,化油器至今仍在割草机、摩托车和小航模发动机上服役。拖「节气门开度」看油随气走,拖「海拔高度」看混合气变稀;按「主油路」看压差吸油链,按「冷启动」看阻风加浓与黑烟,按「怠速过渡」看小孔接力,按「高原稀薄」看空燃比飘红、进气回火。3D 交互演示 · 鼠标拖动旋转 / 滚轮缩放 · 空格播放/暂停
