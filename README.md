# how-things-work

原理展示动画合集。用动画把「看不见的原理」讲清楚 —— 机械机构怎么传动、化学反应怎么断键成键、生物过程怎么一步步发生。

## 目标

- **机制优先**：动画展示的是原理与因果链，不是华丽的转场。
- **可拆解**：每个原理尽量支持分步播放、暂停、单步回看，方便边看边想。
- **自包含**：单个动画尽量不依赖重型构建，打开即可运行。
- **中英双语 · 双主题**：所有页面右上角提供 中文/English 与 深色/浅色 切换，选择通过 localStorage 记住（主题默认跟随系统）。
