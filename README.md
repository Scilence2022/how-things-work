# how-things-work

原理展示动画合集。用动画把「看不见的原理」讲清楚 —— 机械机构怎么传动、化学反应怎么断键成键、生物过程怎么一步步发生。

## 目标

- **机制优先**：动画展示的是原理与因果链，不是华丽的转场。
- **可拆解**：每个原理尽量支持分步播放、暂停、单步回看，方便边看边想。
- **自包含**：单个动画尽量不依赖重型构建，打开即可运行。
- **中英双语 · 双主题**：所有页面右上角提供 中文/English 与 深色/浅色 切换，选择通过 localStorage 记住（主题默认跟随系统）。

### 缝纫机：锁式线迹的形成

- **看什么**：面线如何随针下行成环、旋梭尖如何钩住线环绕梭壳一整圈、底线如何被套住、挑线杆如何收紧成结、送布牙如何推进布料。
- **怎么玩**：鼠标拖动旋转 / 滚轮缩放；`空格` 播放暂停；点击左侧步骤跳转相位；可拖动「相位」滑块逐帧观察。
- **怎么开**：直接用浏览器打开 `sewing-machine/index.html`（首次加载需联网获取 Three.js CDN），或在本目录起一个静态服务：

  ```bash
  python3 -m http.server 8000
  # 打开 http://localhost:8000/sewing-machine/
  ```

- **URL 参数**（调试/分享用）：`?t=0.6` 初始相位（0–1）、`pause=1` 暂停、`speed=1.5` 倍速、`labels=0` 隐藏标签、`housing=0` 隐藏外壳、`spin=0` 关闭自动环绕、`top=1` 俯瞰机位。

### SN2：Walden 反转

- **看什么**：亲核试剂为什么只能从背面 180° 进攻、三角双锥过渡态长什么样、三个基团如何像雨伞一样被翻到另一侧、产物构型为何与反应物互为镜像；右下角能量曲线同步标出唯一过渡态（无中间体）。
- **怎么玩**：与缝纫机相同——`空格` 播放暂停、点击步骤跳相位、相位滑块逐帧；可开关「180° 进攻轴」「电子流向箭头」「能量曲线」。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `spin=`，另有 `top=1` 轴向机位（正对进攻轴检验共线）。

### 勒夏特列：平衡移动

- **看什么**：N₂O₄ ⇌ 2NO₂ 的粒子模拟——正逆反应一直在进行；升温 / 降温 / 压缩 / 膨胀 / 加入 NO₂ 后，正逆速率如何分道扬镳、分子数如何向「削弱扰动」的方向漂移、K 只随温度变而 Q 实时变化。升温颜色变深、压缩总分子数减少，都是从动力学模型里自然长出来的，不是预设动画。
- **怎么玩**：点扰动按钮，观察速率条、Q/K 与净方向提示；四个讲解步骤会随「平衡 → 扰动 → 移动 → 新平衡」自动点亮。

### 原电池：电子与离子迁移

- **看什么**：锌负极溶解吐出 Zn²⁺ 与电子、电子沿导线点亮灯泡流向铜极、Cu²⁺ 上正极析出使蓝色变浅、盐桥中 K⁺ / Cl⁻ 双向迁移维持电中性——外电路（电子）与内电路（离子）合起来才是闭合回路。
- **怎么玩**：自动循环播放，点击步骤跳到对应环节；观察电极消长与溶液颜色随周期缓慢变化。

### 锂离子电池：摇椅模型

- **看什么**：左边红色层板是 LiCoO₂ 正极、右边深灰片是石墨负极，紫色小球是 Li⁺——充电时从正极层间出发、穿过隔膜孔隙钻进石墨层间（层距被撑开约 10%），放电时原路摇回并点亮灯泡，这就是「摇椅电池」。浓度热图实时显示电解液里 Li⁺ 的贫/富翻转；隔膜是电子的绝缘墙——离子走内电路、电子走外电路。
- **怎么玩**：`空格` 播放暂停、点击六步跳相位、相位滑块逐帧；开关「浓度热图」；一定试试琥珀色按钮「过充会怎样？」——看锂枝晶如何刺穿隔膜引发内短路（红色警告：热失控风险），Esc 退出。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=`，另有 `spin=1` 自动环绕。

### SN1：碳正离子中间体与外消旋化

- **看什么**：决速步 C–Br 异裂（Br⁻ 带电子对离去）后，三个烷基压成平面、碳上下张开两瓣**空 p 轨道**——SN1 的招牌瞬间；随后 H₂O 从上、下两面各以 50% 概率进攻，最终并排出现 R/S 两个镜像产物（外消旋 50:50）。右下角能量曲线是「双峰 + 中间体盆地」，灰色虚线叠加 SN2 的单峰作对比；决速步亮出 v = k[RX]——速率与亲核试剂无关。
- **怎么玩**：`空格` 播放暂停、点击步骤跳相位、相位滑块逐帧；拖到 30%–50% 相位细看空 p 轨道；面板底部有 SN2 ⇄ SN1 逐项对比表。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `spin=`，另有 `top=1` 俯视机位（验证三基团共平面）。

### E2：反式共平面与协同消除

- **看什么**：碱摘走 β-H、C–H 电子落成 π 键、C–Br 电子随 Br⁻ 离去——三处变化一拍完成，只有一个过渡态（无中间体），能量曲线与 E1 的「双峰 + 中间体盆地」虚线对比；开局 C–C 单键从重叠式转到对位交叉，只有 **H–Cβ–Cα–Br 四原子共面且反式（二面角 180°）** 时反应才解锁，右上角纽曼投影实时标出二面角与 anti 状态。切到 **t-BuO⁻ 大位阻碱**：内侧 β-H 挤不进去，碱被顶到外侧甲基消除 → Hofmann 产物 1-丁烯（EtO⁻ 小碱 → Zaitsev 产物 2-丁烯）。
- **怎么玩**：`空格` 播放暂停、点击五步跳相位、相位滑块逐帧；勾选「构象探索」亲手转 C–C 键找 anti 构象，转不到 180° 反应锁死；切换碱看区域选择性反转。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `arrows=` `newman=` `base=et/tbu` `spin=`，另有 `top=1` 轴向机位（正对 Cα→Cβ 轴检验反式共平面）。

### E1：碳正离子的分叉路口（与 SN1 共享决速步）

- **看什么**：C–Br 异裂、Br⁻ 带电子对离去后，C₂ 压成平面、空出 p 轨道——SN1 与 E1 在这条最慢的一步上完全共享（v = k[RX]）。分叉随后出现：同一只 H₂O 溶剂，抓整个基团 → SN1（2-丁醇，随后脱质子）；只拿 β-H → E1（空 p 轨道被一对电子填成 π 键，Zaitsev 烯烃为主）。右下角能量曲线共享 ‡₁、各自 ‡₂，虚线是另一条出路；温度滑块实时改变两条出口的产率比（升温利于消除，熵增：一变二）；面板内置 SN1/SN2/E1/E2 四宫格对比。
- **怎么玩**：`空格` 播放暂停、点击五步跳相位、相位滑块逐帧；「出口」按钮切换本周期走 SN1 还是 E1；拖「温度」看 E1/SN1 产率条此消彼长。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `arrows=` `energy=` `spin=` `exit=e1|sn1` `temp=25..80`。

### 缓冲溶液：两支储备军

- **看什么**：烧杯里橙色 CH₃COO⁻ 与蓝色 CH₃COOH 1:1 共存，pH 稳在 pKa 4.76；滴入的 H⁺ 一落地就被橙色军团连线捕获变身 CH₃COOH，pH 只微微颤动——右侧曲线走出缓冲平台，而灰色虚线的清水对照一泻千里；换滴 NaOH 则蓝色 HA 军团电离补 H⁺、再生 A⁻。面板里 Henderson–Hasselbalch 公式的数字跟着粒子实时代入。
- **怎么玩**：「滴加盐酸 / 滴加氢氧化钠」单击一滴、按住连滴（快捷键 A / B）；把任意一支储备军滴光（±1.0 当量），红色警报亮起、pH 崩塌——这就是缓冲容量；「重置」恢复 1:1。
- **URL 参数**：`?acid=` `?base=` 预滴 N 滴（如 `?acid=30` 直达濒临耗尽），`?ref=0` 关对照线，`?speed=` `pause=` `labels=0`。

### 水电解：把原电池倒过来

- **看什么**：直流电源强行把电子从阳极抽走、泵向阴极（电能 → 化学能，非自发）；H⁺ 迁向阴极得电子生 H₂↑、水在阳极失电子生 O₂↑，气泡在电极表面成核、长大、脱附上浮，钻进倒置集气管——氢气体积始终是氧气的 2 倍（2:1 验证）；SO₄²⁻ 是只搬运电荷的「旁观离子」。面板底部固定「原电池 vs 电解池」逐项对比：自发性、能量方向、电子流向、电极名称。
- **怎么玩**：`空格` 播放暂停、点击六步跳相位、相位滑块逐帧；开关「离子迁移」看 H⁺ / SO₄²⁻ 反向迁移闭合回路。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=`，另有 `ion=0` 隐藏离子。

### 酶：诱导契合

- **看什么**：酶的活性中心并非刚性"现成锁"——底物结合诱导两个结构域合拢、催化基团从 ~8 Å 就位到 ~4 Å、敏感键被拉伸活化、断键后产物因不再契合而被释放，酶复原进入下一轮。
- **怎么玩**：`空格` 播放暂停、点击步骤跳相位、相位滑块逐帧；面板实时显示催化基团间距与键长，可开关非共价结合虚线。

### 四冲程内燃机：配气相位

- **看什么**：曲柄滑块带动活塞往复、两只凸轮以半转速驱动进/排气门——气门不是在上/下止点才开关，而是**早开晚闭**（进气提前 20° 开、滞后 50° 关；排气提前 45° 开、滞后 15° 关），排气上止点附近还存在进排气门同时微开的「气门重叠」；缸内气体随冲程变色，压缩上止点前 23° 火花塞点火。右下角 720° 双圈相位图实时标出 IO/IC/EO/EC 与当前曲轴角。
- **怎么玩**：`空格` 播放暂停、点击四冲程步骤跳相位、相位滑块逐帧；重点看 0.985 相位（气门重叠）和点火瞬间。

### 棘轮棘爪：单向离合

- **看什么**：摆臂每往复一次，驱动爪就推着锯齿轮前进一齿（22.5°）；回程时驱动爪翻转张开、沿缓坡滑过齿顶，轮被止回爪死死顶住不动——力只能沿绿箭头方向传递。爪尖接触点用颜色标出受力状态（红=推、黄=滑、橙=落座）。
- **怎么玩**：`空格` 播放暂停、相位滑块逐帧；点「反向驱动演示」看摆臂反着摆时轮为什么纹丝不动。

### 凸轮与从动件：位移曲线

- **看什么**：凸轮轮廓其实就是位移曲线 s(α) 的"卷起来"——右侧把轮廓展开成位移线图，与 3D 滚子高度实时对应；盘面区分升/远休/回/近休四段并着色；区分"理论轮廓（滚子中心轨迹）"与"实际轮廓"。
- **怎么玩**：`空格` 播放暂停、相位滑块逐帧；切换简谐/摆线/等速三种运动规律，轮廓与曲线同步重建；勾选「速度曲线」看等速规律在区段起止点的速度突变（刚性冲击）。

### 差速器：转弯时两轮为什么不一样快

- **看什么**：传动轴 → 主减速锥齿轮 → 差速器壳体；直线行驶时行星轮不自转、整体像刚体；转弯时左右轮必须一快一慢，行星锥齿轮开始自转"吃掉"转速差——n左 + n右 = 2n壳 恒等式由转速表实时验证；地面画出内外轮不同弧长的轨迹（弧长差 = 轮速差的来源）；极端情况单侧悬空：不转侧速度 0、悬空侧 2 倍壳速空转，动力全部流失——这就是限滑差速器存在的理由。
- **怎么玩**：`空格` 播放暂停、点击五步跳相位、相位滑块逐帧；拖「转向」滑块从直线连续调到急弯，看左右轮转速、行星轮自转、地面轨迹实时联动。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `spin=`，另有 `steer=`（−1~1 初始转向）、`case=0` 隐藏壳体、`tracks=0` 隐藏轨迹、`read=0` 隐藏读数、`top=1` 俯瞰行星轮啮合。

### 日内瓦机构：连续旋转如何变成精确间歇

- **看什么**：主动拨轮匀速转一整圈，圆销只在其中 120°（6 槽）里推着从动轮转过精确的 60°，其余 240° 由锁定凸弧嵌在从动轮凹弧座里死死锁住——销到达槽口时运动方向恰好沿槽的径向（切向入槽，不干涉），入/出口角速度为零、加减速连续；右上「转位曲线」就是间歇运动的展开图：平台—S 形爬升—平台，叠加角速度虚线看得更清楚。电影放映机、钟表分度、流水线转位都是它。
- **怎么玩**：`空格` 播放暂停、点击五步跳相位、相位滑块逐帧；切换「4 槽 / 6 槽」看转位角（90°/60°）、驱动角与曲线形状同步变化；勾选「叠加角速度曲线」对比峰值（4 槽 ω比可达 2.4，6 槽仅 1.0）。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `spin=`，另有 `slots=4/6` 槽数、`lock=0` 关锁定高亮、`frame=0` 隐藏机架、`front=1` 正对机位、`vc=1` 默认叠加速度曲线。

### DNA：半保留复制与冈崎片段

- **看什么**：复制叉「工厂」视角——母链持续左穿（⟺ 复制叉右移）：解旋酶撕开双链、SSB 稳住单链；前导链连续合成；后随链上引物酶铺 RNA 引物、聚合酶Ⅲ 反向延伸出冈崎片段、Pol Ⅰ 边切旧引物边补 DNA、连接酶封合最后一个缺口。右上角常驻「半保留复制」示意：两条子代各得一旧一新。
- **怎么玩**：`空格` 播放暂停、点击五步跳相位、相位滑块逐帧；一个周期 = 一个冈崎片段的完整诞生。可开关「标注」与「半保留示意」。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=`，另有 `inset=0` 隐藏示意卡。

### 钠钾泵：构象循环

- **看什么**：Post-Albers 交替通路六步——E1 开口朝胞内捕获 3 Na⁺ → ATP 结合、γ-磷酸基转到泵蛋白上（ADP 脱离）→ 变构 E1-P → E2-P、开口转向胞外（Na⁺ 被短暂「遮蔽」）→ 释放 3 Na⁺ → 结合 2 K⁺ 触发去磷酸化 → 变构回位释放 K⁺。徽章实时显示 E1/E2 与开口朝向，右下角逐条点亮「净效应」：3 Na⁺ 出、2 K⁺ 入、1 ATP。
- **怎么玩**：`空格` 播放暂停、点击六步跳相位、相位滑块逐帧；重点看变构瞬间通道口的朝向翻转与「遮蔽」态。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=`，另有 `bg=0` 隐藏背景离子浓度、`net=0` 隐藏净效应清单。

### 动作电位：去极化 / 复极化

- **看什么**：上方膜电位示波曲线与下方膜片场景严格同相位——阈上刺激跨过 −55 mV 的瞬间正反馈点燃：Na⁺ 激活门开放、Na⁺ 涌入反极化到 +36 mV；峰值处失活球（球-链闸门）堵住通道、K⁺ 通道延迟开放；K⁺ 外流复极化、跌破静息成超极化；最后闸门复位、泵与漏通道恢复梯度。电荷符号随电位实时翻转，曲线下方标出绝对/相对不应期。

### 卡尔文循环

- **看什么**：碳固定 → 还原 → RuBP 再生一整圈——Rubisco 把 CO₂ 加到 5C 的 RuBP 上裂解成 2 个 3-PGA；ATP、NADPH 从「类囊体」站飞入（ADP/NADP⁺ 飞回循环）；分子卡片上的圆点数 = 碳原子数，碳守恒一目了然；1/6 的 G3P 带着碳离开，右下「碳账本」逐条点亮：每 3 CO₂ 耗 9 ATP + 6 NADPH、净得 1 G3P。
- **怎么玩**：`空格` 播放暂停、点击六步跳相位、相位滑块逐帧。

### ATP 合酶：质子流驱动的旋转催化

- **看什么**：膜间隙的 H⁺ 顺浓度梯度钻进 a 亚基入口半通道、结合到经过的 c 亚基上随环转过一整圈、从出口离开进入基质——c 环被推着转，γ 轴像曲轴一样把扭矩传进 F1，三个 β 亚基被依次强迫 开放 O（结合 ADP+Pi）→ 松散 L（夹住底物）→ 紧密 T（挤压缩合成 ATP）→ 回摆释放。转子（c 环 + γ 轴）严格刚性同步，定子臂扣住 F1 不让它跟着转；顶部计数器每 120° 弹出一个 ATP，一圈 = 3 个 ATP。
- **怎么玩**：`空格` 播放暂停、点击六步跳相位、相位滑块逐帧；盯住任意一颗 β 药丸，看它的构象字母与货物（ADP+Pi / ATP）沿同一时间线走完一整圈。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=` `spin=`，另有 `protons=0` 隐藏 H⁺、`states=0` 隐藏构象标签、`highlight=0` 关状态高亮、`membrane=0` 隐藏膜、`top=1` 俯瞰机位。

### 线粒体电子传递链：电子下坡，质子上坡

- **看什么**：内膜「工厂」——NADH 在复合体 Ⅰ 交出 2 e⁻（泵 4 H⁺），泛醌 CoQ 在膜内摆渡到 Ⅲ（再泵 4 H⁺），细胞色素 c 沿膜间隙面小跑把电子送到 Ⅳ；O₂ 从上方进来，与 4 e⁻ + 4 H⁺ 化合成 2 个 H₂O（再泵 2 H⁺）——「呼吸」的终点落在画面右端。电子一路下坡（颜色渐暗），质子被一路泵上膜间隙；最后 10 个 H⁺ 顺梯度经 ATP 合酶流回，转子每 120° 弹出一个 ATP（每 NADH ≈2.5，FADH₂ 从 Ⅱ 进入少泵 4 H⁺ 的换算写在步骤 5）。计数面板实时显示已泵 H⁺ 与 ATP。
- **怎么玩**：`空格` 播放暂停、点击五步跳相位、相位滑块逐帧；重点试「DNP 解偶联彩蛋」——膜上打孔让梯度短路，ATP 停产、产热飙升（棕色脂肪产热同款原理）。
- **URL 参数**：`?t=` `pause=` `speed=` `labels=0` `dnp=1`。

### 肌肉收缩：横桥循环

- **看什么**：Ca²⁺ 结合肌钙蛋白、原肌球蛋白旋离暴露位点；储能的肌球蛋白头部咬合成横桥，Pi 释放触发 Power stroke 把细肌丝拖向 M 线 ≈10 nm；无 ATP 则锁死在 Rigor 态（尸僵的根源），ATP 结合才松手、水解储能回位——ATP 的作用是「让肌丝松手」而不是直接 powering。
